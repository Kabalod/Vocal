# Vocal: инструкции для Cursor по личному MVP

Дата подготовки: 2026-09-07.
Репозиторий: https://github.com/Kabalod/Vocal
Проверенная исходная версия: b59e78a0a177442dd7fc30e02217153c634eb98f.

## Как использовать

1. Распакуй архив. Инструкции можно положить в `docs/cursor-plan/` проекта.
2. Открой проект Vocal в Cursor.
3. Для первого запуска приложи `CURSOR_COMMON.md` и `STAGE_00_baseline.md`.
4. Напиши: «Выполни только этап 0 по приложенной инструкции. Подготовь
   коммит, отправь рабочую ветку и остановись для внешней проверки».
5. Полученный отчёт со ссылкой на ветку/PR и SHA передай в чат с ChatGPT.
6. После ревью Cursor исправляет замечания текущего этапа. Следующий этап
   начинается после явного принятия. Для него приложи соответствующий файл.

Каждая инструкция содержит общие правила и может использоваться отдельно.
Общий файл — удобная единая памятка, а не ещё один этап.

## Как устроено ревью

Работа ведётся в рабочих ветках. После этапа Cursor записывает BASE_SHA и HEAD_SHA,
запускает проверки и отправляет ветку. ChatGPT читает изменения через GitHub,
проверяет связанные файлы и формирует замечания. Автоматического фонового
наблюдения за репозиторием нет: пользователь присылает отчёт после этапа.

Если предыдущий этап ещё не слит, следующий нельзя начинать от отстающего main.
Проверка diff всегда выполняется от указанного BASE_SHA, чтобы не пересматривать
все прежние изменения. Исправления идут в ту же ветку без force push.
Слияние не входит в автоматическое завершение этапа.

Внешний просмотр исходников не доказывает работу медиа на твоём устройстве.
Различай: проверено по коду, проверено тестом, проверено ручным запуском,
не проверено. Используй REVIEW_TEMPLATE.md.

## Пять требований продукта

- Каждая идея — отдельная карточка, существующая до видео.
- Дубли и вопросы можно продолжать без общего лимита итераций.
- Сценарий собирается из выбранного материала, редактируется и версионируется.
- Анкета описывает цели, жизнь, интересы и границы автора.
- Управление данными работает без ИИ; содержательные действия запускаются явно.

## Объём первой версии

Один автор, локальный запуск, существующий Next.js/SQLite/Prisma/Groq.
Загрузка готовых видео/аудио и ввод текста; запись через камеру в браузере,
автопубликация, монтаж, аккаунты и биллинг не входят в эти этапы.
Новые версии моделей и изменение провайдера не являются условием разработки.
Результаты старого анализа сохраняются, но скоринг не блокирует новую помощь.

## Критерий окончания

Можно создать идею, загрузить несколько попыток, исправить текст, получить
вопросы, ответить, собрать сценарий, записать новый дубль и вернуться к любой
сохранённой версии. Перезапуск и ошибка ИИ не уничтожают работу.

Содержимое архива — инструкции, а не уже выполненные изменения проекта.
