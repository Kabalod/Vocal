### 2. `src/components/TakeComparison.tsx`

### Сравнение

Покажи текстовые изменения обычным кодом. Смысловое сравнение отвечает,
сохранилась ли мысль и реализовано ли выбранное намерение правки.
Не объявляй новый дубль автоматически лучшим. Финальный выбирает автор.

### Экспорт и копирование

Экспорт карточки включает идею, версии текста, вопросы/ответы, сценарии,
метаданные дублей и разборов. Не включай всю личную анкету и скрытый контекст
без явного выбора. Не экспортируй ключи, внутренние абсолютные пути и .env.
Резервная копия локального приложения отдельно сохраняет БД и медиа;
проверь восстановление в изолированную директорию, не поверх рабочей БД.

### Полный пользовательский прогон

Анкета → две идеи → несколько дублей в одной → правка расшифровки → разбор
→ ответы → сценарий → ручная правка → новый дубль по сценарию → сравнение
→ выбор финального → перезапуск → проверка сохранности → экспорт.

Проверь отдельно: нет ключа ИИ, неудачный ответ модели, сетевой сбой,
перезапуск, двойное нажатие, неподдерживаемый файл и устаревший результат.
Автопроверки — с mock-провайдером. Реальные микрофон/камера не реализованы
этим планом; просмотр и загрузку на Windows нужно подтвердить локально.
Не публикуй приложение в интернет как часть итоговой проверки.
