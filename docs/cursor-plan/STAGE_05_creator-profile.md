11. Обнови docs/IMPLEMENTATION_STATUS.md и подготовь отчёт по REVIEW_TEMPLATE.md.
    Выполни доступные проверки типов, линтер и сборку; отдели исходные ошибки.
12. Сделай коммит этапа и отправь рабочую ветку в GitHub, если доступ настроен.
    Не делай force push и не сливай в main автоматически. Если push недоступен,

13. Остановись до внешней проверки. Следующий этап начинается после принятия

Это личное приложение для одного автора. Работа через localhost не требует
системы аккаунтов. Если приложение станет доступно по сети, доступ к личным
материалам нужно защитить до публикации; не открывай его наружу в этом этапе.

## Порядок работы по файлам

### 1. `prisma/schema.prisma; prisma/migrations/<migration>/migration.sql`

CreatorProfile и версии профиля либо неизменяемые snapshots. Один автор без системы аккаунтов.

### 2. `src/types/profile.ts`

Поля, разрешения использования и валидация.

### 3. `src/lib/profile.ts`

Сохранение профиля и версий.

### 4. `src/app/api/profile/route.ts`

Чтение и сохранение, без ИИ.

### 5. `src/components/ProfileForm.tsx`

Восемь блоков анкеты, черновик, сохранение и ошибки.

### 6. `src/app/profile/page.tsx`

Экран анкеты и доступ из навигации.

### 7. `src/lib/reel-context.ts`

Детерминированный выбор контекста для конкретной карточки.

### 8. `src/app/reels/[id]/page.tsx`

Цель и аудитория конкретного ролика, выбор разрешённых полей контекста.

### Поля анкеты

1. Зачем записываю ролики.
2. К какой цели двигаюсь.
3. С кем хочу общаться через блог.
4. Какая у меня сейчас жизнь.
5. Мой опыт и интересы.
6. Какие темы хочу раскрывать.
7. Как хочу говорить.
8. Что не хочу раскрывать.

Не заполняй анкету реальными данными автора из догадок или истории чатов.
Каждый личный материал помечается: «можно использовать в тексте» либо
«только для понимания». Второй тип не подставляется в сценарий как публичный
эпизод. Пользователь должен видеть, какой контекст будет отправлен модели.

Контекст = разрешённые выбранные поля + цель конкретного ролика + аудитория.
Не отправляй всю биографию во все вызовы. Цель карточки может отличаться от
общей цели блога. Изменение профиля не меняет старые разборы задним числом.

## Условия готовности

- [ ] Анкета сохраняется и открывается без API-ключа.
- [ ] Можно редактировать и пропускать поля.
- [ ] Контекст карточки воспроизводим без ИИ.
- [ ] Не выбранные поля исключаются.
- [ ] Старые версии контекста остаются доступными для истории.

## Что проверяет внешний ревьюер

Приватность полей, контекст, версии и отсутствие автоматического вывода о личности.
