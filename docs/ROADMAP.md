## Рекомендуемый порядок

1. **Принять C00-05**, затем **принять продукт C00**. C00-01–C00-04 уже приняты. C00-05 реализован, не принят.
2. Отдельно **принять Auth** и решить совместимость live-схемы **без** переноса старых пользовательских данных. Новые таблицы или колонки — только если они нужны будущему контракту; это создание схемы, не импорт содержимого.
3. Реализовать и **принять V04** (портрет из profile dialogue; не мост из thought-исправлений).
4. Затем **V05 → V06 → V07**.
5. После этого — только **недостающие** задачи межмыслевой памяти, надёжности и сквозной оценки (остаток I04 / I07 / I08 и отдельный контракт моста).
6. Проверки интерфейса и запуска. **Оплата** — отдельный шаг перед **платным** запуском, не часть C00 и не часть V.

Подготовительную работу (черновики контрактов, UI-фикстуры, чтение drift) можно вести параллельно. Продуктовые приёмки **не подменяют** друг друга: принятый C00 не есть принятый V04; принятый Auth не есть принятая live-схема.

## Мост, которого нет

**Повторные наблюдения из разных мыслей → обоснованное предпочтение автора.**

C00 исправляет **текущую** мысль и **не** пишет портрет. V04-00 принимает источники только из **profile dialogue**. Перенос «несколько локальных правок → память автора» задним числом в C00 или в текущий V04-00 **запрещён**. Это отдельное изменение контракта источников V04 и отдельная приёмка после принятых C00 и V04.

## Готовность к запуску (не статус «готово»)

Все пункты ниже — **условия**, не отметки о выполнении:

1. Полный цикл мысли и дублей: создать → диалог → сценарий (V05) → запись → разбор (V06) → завершение.
2. Проверка качества ответов на **реальной** модели (не только mocks).
3. Изоляция двух пользователей (после приёмки Auth).
4. Актуальная схема базы (репо и live согласованы без импорта старого содержимого).
5. Расходы и лимиты AI на всех путях, не только thought dialogue.
6. Защита входа и ответов во всех AI-путях.
7. Удаление данных пользователя и запрет replay удалённого.
8. Desktop / mobile E2E по утверждённым экранам 01–09.

Оплата не входит в этот список как часть C00/V. Она отдельным решением перед платным запуском.
