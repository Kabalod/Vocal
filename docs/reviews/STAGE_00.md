### Исходные ошибки проекта (не чинились в этапе 0)

1. `scripts/score-analyz.ts:93` — TS1501: флаг регулярного выражения `s` (в литерале `/…/is`) доступен только при target `es2018` или новее; в `tsconfig.json` сейчас `"target": "ES2017"`. Ошибка видна в `typecheck` и первой падает `build`. Не скрывалась исключением `scripts` из `exclude`.
2. `src/lib/analyze.ts` — ряд ошибок strict TypeScript (TS18048 / TS2322 / TS2345), начиная с строки 395: `parsed.video` possibly undefined и несовместимость optional-полей Zod с обязательными типами. Файл в этом исправлении не менялся. `typecheck` показывает их после ошибки скрипта; `next build` на них не доходит, пока не закрыт TS1501.
