## Что реализовано

- Главный экран `/reels` называется «Мысли»; в shell то же имя. URL `/reels` сохранён.
- Четыре фильтра: Все / Не завершена / В работе / Успешно завершена; на 390px сетка 2×2. Чипы «Идея / Готов к записи / Архив» с экрана сняты.
- Группы без миграции: `idea`/`draft` → Не завершена; `in_progress`/`active`/`ready_to_record` → В работе; `completed` → Успешно завершена; `archived` не входит в «Все».
- Desktop ≥1200: список ~58% и превью выбранной мысли; клик по карточке не уходит со списка; «Открыть мысль» ведёт в студию. Детали грузятся `GET /api/reels/:id`.
- Mobile: полноэкранный список, «Меню», без постоянного профиля и без dock; тап открывает мысль. `scrollWidth` на 390px = 390.
- Один primary «Новая мысль»: в шапке при наличии данных; в empty — по центру; в шапке при пустом списке место занято (`invisible`). Способы создания не реализованы (кнопка не POST и не открывает picker).
- Empty: нет мыслей; нет поиска; нет фильтра. Ошибка списка отдельно. Поиск «Найти мысль» с accessible name и «Очистить». Счётчики «Всего / Найдено».
- `GET /api/reels`: компактный DTO (id, title, status, statusGroup, preview, счётчики, timestamps), без takes/сценариев/транскриптов. Cursor pagination и «Загрузить ещё». Поиск и фильтры без AI.
