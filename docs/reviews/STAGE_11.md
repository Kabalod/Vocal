## Что реализовано

- Сквозная проверка личного продукта без новых пользовательских функций.
- Служебная сводка `AiCall`: `npm run report:ai` и `/dev/ai` в development (день, контекст reel/profile, вид, модель, вызовы, prompt/completion/total). В production `/dev/ai` недоступна.
- `tests/mvp-release.test.ts`: пустой список → текстовая мысль → диалог → перенос в черновик → правка → готовая версия; голосовой ответ в диалоге не плодит дубли/версии; независимые итоги → завершение → возврат с той же историей; пропуск анкеты → портрет → контекст новой мысли; дневной лимит с понятной ошибкой; backup/restore по checksum; список без полных материалов; версии в workspace без массового body.
- README приведён к текущему продукту (мысли, диалог, портрет, запись, статусы).
- Браузер: навигация только «Мысли» / «Профиль», те же пользовательские статусы, профиль-разговор на 390 и 1280.
