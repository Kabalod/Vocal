## Реализовано

Миграции: на существующей `prisma/dev.db` pending не было (8 уже применены); на чистой временной SQLite те же 8 применились. Новой миграции схемы нет.

Ручной smoke (вымышленный чай): пустой список, создание идеи, повторное нажатие «Создаём…» / «Сохраняем…», два текстовых дубля, правка расшифровки, две версии сценария и финальный сценарий, текстовый diff, экспорт, 409 по устаревшему PATCH, финальный дубль, загрузка тестового mp3 и `GET` медиа 200. Пустые состояния: нет идей, нет попыток, «без файла», нет разборов и вопросов. Длинный текст: API `TEXT_TOO_LONG` на 20001 символ. Backup/restore в изолированный каталог.
