## Вердикт совместимости

Целевое ядро (диалог → состояние мысли → сценарий → выбор дубля → завершение) **совместимо со стеком** Next 15 + Prisma 6 + Postgres + Groq + существующие Reel / Take / Dialogue / Script / AiCall.

**Не совместимо без отдельных этапов V01+** с текущим поведением:

1. Нет модели и reducer `ThoughtState`. Статус мысли — строка `Reel.status` (`draft` / `in_progress` / `completed` и алиасы в фильтрах).
2. Нет поля `workingTakeId`. Есть `selectedTakeId` и `finalTakeId`.
3. Контекст диалога грузит `takes: { take: 2 }` — в выборку попадают только два дубля по `number`.
4. Нет handler `suggest_take`.
5. `confirmProfilePortrait` и `readyToConfirm` **на месте** (I05 / не V00).
6. `withAiInflight` дедуплицирует промис по ключу и **не бросает** 409, хотя класс `AiInflightError` объявлен.
7. Два пути Groq (как в I00): `complete.ts`+`AiCall` и pipeline/analyze без единого транспорта.

Главные решения плана ядра имеют приоритет над локальными незакоммиченными «открытие мысли» и «dialogue-reply», пока они не приняты отдельным этапом.
