# V04 — сценарии приёмки

Ожидаемое поведение **после продуктовых коммитов** V04. На V04-00 код ещё прежний (confirm обязателен). V04 не принят.

V04_BASE_SHA: `564c9cf8534392501e125dda7ecc747c235a5c0d`.

1. **Устойчивое остаётся.** Автор говорит общую цель и аудиторию. Ревизия содержит эти сведения. Деталей «о чём ролик на этой неделе» в портрете нет.
2. **Эпизод мысли отброшен.** В диалоге профиля автор пересказывает конкретный разговор или дубль. Глобальные поля не получают сюжет. Мысль и `ThoughtState` не меняются из профиля.
3. **Нет поддержки и ярлыков.** Модель не хвалит, не ободряет, не ставит диагноз. Если сырой ответ модели содержит оценку или ярлык, сервер не записывает их в ревизию.
4. **Один вопрос к ясной мысли.** За ход один смысловой вопрос. Пустые поля чеклиста не склеиваются в одну реплику. Отказ отвечать оставляет поле пустым.
5. **Авторевизия.** Есть действующий портрет. Автор уточняет подачу. Появляется новая `ProfileRevision` без `action=confirm`. Старая ревизия не затирается в истории.
6. **Confirm нет.** `POST` с `action=confirm` не требуется и не является шагом публикации. UI без кнопки «Подтвердить портрет» и без «черновик не действует».
7. **Просмотр и разговор.** Пользователь видит действующий портрет и может сразу написать следующее уточнение.
8. **Нет ручных весов.** Нет слайдеров, ручного `usage` и PUT полей как способа настроить портрет.
9. **Цикл без портрета.** Skip или пустой профиль: создание мысли, `ask_question` / `suggest_take` / запись дубля работают. Нет блокировки onboarding.
10. **Мысль важнее портрета.** В ThoughtState есть факт, противоречащий общему портрету. Вопрос и помощь следуют мысли. Портрет не становится `fact` и не закрывает gap.
11. **Не источник сценария.** Поля портрета не попадают в черновик сценария как события или факты ролика. `publicForScript` не копирует биографию в текст.
12. **Пустая ревизия.** Повтор без нового смысла не создаёт лишнюю ревизию. Повтор с тем же ключом диалога не вызывает модель второй раз (как сейчас по idempotencyKey).

Вне сценариев V04: вкладка «Сценарий» (V05), completion (V06), live migrate.
