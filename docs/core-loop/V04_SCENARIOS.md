Ожидаемое поведение **после продуктовых коммитов** V04. На V04-00 код ещё прежний (confirm обязателен, плоский patch). V04 не принят.

## Контракт обновления

1. **Прямая общая цель.** Автор в profile dialogue говорит общую цель блога как постоянную характеристику. Кандидат: прямая категория, `scope=global`, `evidenceType=explicit_statement`, `operation=replace_explicit`, основание — это сообщение пользователя. Действующий портрет обновляется из одного ответа. Новая `ProfileRevision` без confirm.
2. **Одна случайная особенность речи.** Одна реплика вроде разовой манеры объяснять. Кандидат не публикует устойчивую характеристику. Допустимы `add_observation` или `no_change`. Действующий портрет и набор `ProfileRevision` не меняются (основание может сохраниться без новой ревизии).
3. **Согласованные наблюдения.** Несколько сообщений пользователя profile dialogue согласованно указывают на одну особенность коммуникации. Вес и уверенность растут (`strengthen`). После порога особенность входит в действующий портрет. «Тип автора» как ярлык не появляется.
4. **Противоречивое наблюдение.** Новое основание расходится с уже накопленным. `weaken`: уверенность или вес падают. Характеристика автоматически не затирается. История оснований на месте.
5. **Настроение не характеристика.** «Сегодня не в духе» / разовое состояние. В действующий портрет не попадает. Не прямая категория и не устойчивая особенность.
6. **Только user + profile dialogue.** `evidenceMessageIds` принимаются, только если каждый id — существующее сообщение роли `user` в треде профиля. Иначе кандидат не публикуется.
7. **Сообщение ассистента не основание.** Id ответа модели в `evidenceMessageIds` — отказ публикации. Действующий портрет не меняется.
8. **Деталь мысли.** Модель помечает `scope=thought_specific` (сюжет ролика, разговор этой мысли). Сервер не публикует в глобальный портрет. `ThoughtState` из профиля не меняется.
9. **Повтор без значимости.** Тот же смысл или слабое одиночное наблюдение. Новой `ProfileRevision` нет. Действующий портрет тот же. Основание при необходимости дописывается без смены среза.
10. **Значимое изменение без confirm.** Принятое прямое общее утверждение или производная особенность, прошедшая порог. Новая `ProfileRevision`. `action=confirm` не нужен. UI без «Подтвердить портрет».

## Соседние инварианты

11. **Один вопрос.** За ход один смысловой вопрос. Отказ отвечать оставляет прямую категорию пустой.
12. **Нет поддержки и ярлыков.** Похвала, ободрение, диагноз, категоричный тип в действующую ревизию не пишутся.
13. **Просмотр и разговор.** Пользователь видит действующий портрет и может уточнить дальше. Слайдеров и ручных весов нет.
14. **Цикл без портрета.** Skip или пустой профиль не блокирует мысль, V03 и запись дубля.
15. **Мысль важнее портрета.** Факт `ThoughtState` важнее предположения портрета. Портрет не становится `fact` и не закрывает gap.
16. **Не источник сценария.** Портрет не события и не факты черновика сценария.
