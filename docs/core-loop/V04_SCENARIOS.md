# V04 — сценарии приёмки

Ожидаемое поведение **после продуктовых коммитов** V04. На V04-00 код ещё прежний. V04 не принят.

V04_BASE_SHA: `564c9cf8534392501e125dda7ecc747c235a5c0d`.

Пороги: `COUNTING_MIN_CONFIDENCE = 0.5`, `PUBLISH_THRESHOLD = 3`, `REMOVE_THRESHOLD = 1`. Сервер не разбирает смысл `value`.

## Структура и источники

1. **Confidence вне диапазона.** Кандидат с `confidence` `-0.1`, `1.1` или не число. Отказ. Журнал, портрет, `ProfileRevision` без изменений.
2. **Неизвестная категория.** `category=mood` / `praise` / `diagnosis` / любой ключ вне enum. Отказ. В портрет ничего не попадает — не потому что сервер «понял» текст, а потому что категории нет в enum.
3. **Повторный evidenceMessageId.** Дубль в одном массиве **или** id уже есть в журнале слота для той же роли. Отказ. Вес не меняется.
4. **Ассистент / чужой thread / мысль.** Id сообщения ассистента, другого владельца, не profile thread или диалога мысли. Отказ.
5. **Несовместимый переход.** `replace_explicit` + производная категория, или `behavioral_observation` + прямая категория. Отказ.

## Прямые сведения и scope

6. **Прямая общая цель.** `blog_goal` + `explicit_statement` + `replace_explicit` + `scope=global` + один user id profile dialogue + `confidence` ∈ [0, 1]. Отображаемое значение меняется. Новая `ProfileRevision` без confirm.
7. **Повтор того же прямого value.** Нормализованная строка совпадает с действующей. Журнал может учесть ход как повтор; новой `ProfileRevision` нет.
8. **thought_specific.** `scope=thought_specific` (деталь мысли). Глобальный портрет и ревизии не меняются. `ThoughtState` из профиля не пишется.

## Вес производных

9. **Одно behavioral observation ниже порога.** `add_observation`, новый слот, `confidence >= 0.5`, `support_n = 1`. В журнал да, в действующий портрет нет, новой `ProfileRevision` нет.
10. **Слабое основание.** `confidence = 0.4`. Запись в журнал, `system_weight` не растёт, портрет и ревизии те же.
11. **Три независимых основания, порог публикации.** Три разных user id, `strengthen` / `add_observation`, каждый `confidence >= 0.5`, один `(category, value)`. `system_weight` становится 3. Особенность появляется в действующем портрете. Новая `ProfileRevision`.
12. **Strengthen уже опубликованного.** Четвёртое согласованное основание. Вес 4. Отображаемое значение то же. Новой `ProfileRevision` нет.
13. **Weaken без порога удаления.** Опубликованный слот, вес 3. Один `weaken` с новым id и `confidence >= 0.5`. Вес 2, слот остаётся опубликован (`REMOVE_THRESHOLD = 1`). История oppose на месте. Новой `ProfileRevision` нет.
14. **Weaken с порогом удаления.** Ещё weaken, пока `system_weight <= 1`. Слот снят с действующего портрета. Новая `ProfileRevision`. Журнал не затирается.
15. **Изменение внутреннего веса без новой ревизии.** Любой принятый `add_observation` / `strengthen` / `weaken`, после которого отображаемый срез тот же. `ProfileRevision` не создаётся.

17. **Нет confirm и слайдеров.** Публикация по таблицам и порогам. UI без «Подтвердить портрет».
18. **Цикл без портрета.** Skip не блокирует мысль и V03.
19. **Мысль важнее портрета.** Портрет не `fact` и не закрывает gap.
20. **Не источник сценария.** Портрет не события черновика сценария.
