# V00 — зависимости, без которых V01 нельзя начинать

V00 — аудит. Он **не** снимает блокеры ниже. Матрица: [`PLAN.md`](./PLAN.md).

## Блокеры V01

1. **Приёмка документов V00** (повторное внешнее ревью). Пока нет — код ядра не менять.
2. **Назначенный BASE_SHA.** Кандидат приложения: `4ac28630692860a3092cf6c4cbc05ed791eb549d`. Сейчас **not assigned**.
3. **Приёмка Auth** как продукта. Код на кандидате есть. Самоподтверждение и A/B — не база.
4. **Приёмка лендинга** — блокер чистоты дерева, не логики диалога. Не смешивать V01 с незакоммиченным лендингом/Auth-polish.
5. **Грязное дерево.** `dialogue-reply`, `thought-opening`, вынесенный `thought-completion-gate` и прочий uncommitted код не входят в кандидата.

## Не блокеры старта принятого V01 (свои этапы)

- Нет четырёх действий агента — **V03**.
- Confirm портрета — снимается на **V04**, не выносится из цикла.
- Роль сценария и кнопка записи — **V05**.
- Завершение без обязательного `finalScriptId` — **V06**.

V01 после BASE делает: актуальный дубль, точную ревизию, изоляцию запросов (ключ с `ownerUserId`).
