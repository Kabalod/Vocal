# V01 — сценарии

Ожидаемое поведение кода после fix-коммитов. Приёмки нет, пока пользователь не примет этап.

1. **Третий дубль.** `workingTakeId` = третий, `selectedTakeId` = первый → промпт содержит только материал третьего и id его ревизии.
2. **Нет указателя.** `workingTakeId` null при живых takes → диалог не берёт `takes[0]`, ошибка `WORKING_TAKE_REQUIRED`.
3. **Смена дубля во время модели.** Ответ не пишется, 409, в ленте нет текста модели.
4. **Смена ревизии во время модели.** То же.
5. **Чужое сообщение в треде во время модели.** То же.
6. **Две мысли, один `idempotencyKey`.** Два вызова модели.
7. **Ошибка модели.** Ключ inflight снимается, повтор ключа с тем же процессом снова входит в `run`.
8. **PATCH своего дубля.** 200, `finalTakeId` не меняется.
9. **PATCH дубля другой мысли.** 400 `TAKE_NOT_IN_REEL`.
10. **Снимок `AiCall`.** Есть `workingTakeId`, `transcriptRevisionId`, `reelUpdatedAt`, `dialogueVersion`.
11. **Клиентский stale `expectedUpdatedAt`.** 409 до модели.

Вне сценариев: ThoughtState, четыре действия, запись, завершение без сценария.
