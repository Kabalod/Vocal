# V02 — сценарии

Ожидаемое поведение принятого V02 (`V02_HEAD` `1c9a4b9d4fda8df91b2e650e217883c8e02ccc62`). V03 не начат.

1. **Создание мысли.** Есть `ThoughtState`, `workingTakeId` совпадает с Reel.
2. **Пустая карточка.** Состояние есть, указатель пуст; первый дубль его заполняет.
3. **Смена рабочего дубля.** Состояние указывает на новый take, `revision` растёт.
4. **Устаревшая ревизия.** `applyThoughtState` с старым `expectedRevision` → 409, замысел не меняется, сообщений диалога нет.
5. **Чужой дубль.** База отклоняет `ThoughtState.workingTakeId` от другой мысли.
6. **Не биография.** В состоянии нет полей глобального портрета; `audienceLocal` относится только к этой мысли.
7. **Факт без источника автора.** Строка или сообщение ассистента не становятся фактом.
8. **Владелец.** Пользователь B не читает и не меняет состояние A; revision A не меняется.
9. **Backfill.** Reel с дублем и без, созданные до миграции 6, получают согласованный ThoughtState.
