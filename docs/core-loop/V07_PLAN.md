## Принятый объём V07

Два продукта внутри этапа (runtime-селектор и синтетический цикл). Исследовательский корпус I06 и живая оценка I08 не входят.

### 1. Библиотека приёмов → выбор вопроса

- Версионируемый файл/каталог в репозитории, без векторной БД и без новых колонок Prisma.
- Карточка минимум: `id`, `version`, применимый пробел / режим, механизм, стратегия вопроса, противопоказания. Технические фикстуры отдельно от исследовательских карточек.
- Селектор: 0–4 карточки по **текущему открытому пробелу** и режиму мысли. Ноль — допустимый и частый результат. Несовместимый режим исключает карточку.
- Подключение только к формулировке `ask_question`. Четыре действия V03 не расширять. Сценарий, `suggest_take`, `content_sufficient` и C00 не получают пятого действия и не генерируют сценарий из приёма.
- Снимок хода (`AiCall.inputSnapshotJson`) фиксирует версию каталога и id выбранных карточек. Сейчас там `playbook: false` без craft.
- Пустой каталог и флаг отключения не ломают диалог, не теряют ThoughtState / дубли / сценарии.
- Чужие истории, фразы и манеру не копировать в вопрос. Не заставлять каждый ход содержать «хук / конфликт / CTA» или дерево причин.
- Стартовый набор — только из **доступных проверенных** материалов. Если таких карточек нет, каталог пустой; ограничение содержания зафиксировать честно. Не сочинять анализ корпуса.

Пересечение с I06: V07 закрывает **runtime селектора в цикле мысли**. Полный исследовательский каталог (source reel IDs, attribution гостя, duplicateGroup, evidenceStatus по корпусу) остаётся I06 и **не** принимается вместе с V07.

### 2. Полный цикл на фиксированных синтетических кейсах

Детерминированные прогоны уже принятого пути плюс селектор:

- личная история; объяснение; короткое наблюдение; уже готовая мысль;
- недостаточный материал; противоречие; смена замысла;
- длинный диалог; три и более дубля;
- отсутствие портрета; обновление портрета (уже принятый V04, не мост);
- отказ отвечать; уход от задачи / смена правил агента (`redirect_to_task` / C00).

Критерий: тот же, что в каноне цикла — вопрос закрывает пробел; задача дубля понятна; процесс не тянется без причины; `content_sufficient` только после обработанного медиа-дубля; итоговый дубль выбирает пользователь.

Изоляция пользователей, повтор хода, 409 по версии, ошибка модели без потери материала — регрессия уже принятых V01–V03, не новый продукт Auth.
