# V03 — сценарии

Ожидаемое поведение кода V03. Приёмки нет, пока пользователь не примет этап.

1. **ask_question.** Вопрос с `gapId` открытого пробела или причиной уточнения сохраняется; статус карточки тот же. Закрытый или несуществующий `gapId` отклоняется.
2. **suggest_take.** Есть замысел, задача дубля и ссылки на факты мысли. Содержательный ответ автора становится фактом; команда «можно снимать» факт не пишет; `takeTask` сохраняется в ThoughtState.
3. **content_sufficient** без обработанного audio/video дубля → 400.
4. **redirect_to_task.** Возврат к текущей задаче, без новой темы и без смены статуса.
5. **Старый JSON.** `reply` + `scriptProposal` отклоняется. Лишние поля у валидного действия тоже отклоняются.
6. **Действие ≠ статус.** После любого валидного действия `Reel.status` не становится именем действия.
7. **CAS ThoughtState.** Смена `ThoughtState` во время ответа модели → 409, сообщение действия не пишется, `AiCall` в ошибке.
8. **Команды и redirect.** `снимай` / `хватит` / `уточни` и `redirect_to_task` не создают факты.
9. **Пробел.** Содержательный ответ на вопрос с `gapId` закрывает этот пробел.
10. **Восстановление.** Ошибка обновления ThoughtState после сообщения; повтор того же ключа завершает ход один раз без второго вызова модели.

Вне сценариев: UI записи, confirm портрета, завершение без сценария.
