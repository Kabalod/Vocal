## Что важно знать (ограничения)

1. **Вопрос «один случай» (P04) не найден в корпусе.** Авторы сами делают абстракцию конкретной моделью; прямой вопрос — моя инверсия. Потребность подтверждена только наблюдением R5 (мало вопросов про случай). Статус «кандидат» означает лишь «основание для операции есть», действие вопроса не проверено (K5).
2. **Опровержение не независимое.** Отдельный проход «без доступа к пути вывода» агентом не запускался; опровержение сделано мной на сжатом материале. Если нужен настоящий независимый проход, нужна ваша команда.
3. Отнесение заголовков к семействам по ключевым словам: грубое; лексический прокси повторяемости шумный (маркеры вроде «например» есть у любой речи). Корпус смещён к экспертам; жанры «юмор, путешествия, бизнес, лайфстайл» не покрыты.
4. Живая модель в K1–K3 не использовалась, токены не тратились.
