# K5-lite: пары вопросов для слепой оценки

Для каждого дубля два вопроса автору (А и Б). Какой из них написан с карточкой, не указано (ключ отдельно: `k5lite_key.json`, смотреть после оценки). Тексты дублей сюда не копируются: открывайте дубль по id в корпусе `Analyz` (источник указан). Оценка: для каждого вопроса отметьте да / нет / частично по четырём критериям. **Результат не доказывает поведение рабочей модели Groq**: вопросы написаны Claude в IDE, без провайдера.

Критерии: **1** вопрос попал в пробел; **2** автор сможет ответить содержательно; **3** нет выдумок и подсказок ответа; **4** нет цитат блогеров.
