## Что видно в тексте

- Паразиты и ошибки распознавания в сценарий не попали: в просмотренных примерах «потаму» → «потому», «привращается» → «превращается», «я я сидела … э-э … э-э» → связная фраза. Это делает модель по запросу; сервер вырезает паразитов дополнительно (в сценариях 0).
- Сохранение слов выросло с 26–29 % до 45–48 % в основном потому, что ответы автора, не ставшие фактами, теперь входят во вход сборки (E2, решение 1). Остальные 52–55 % фраз не попали: сценарий пересказывает, а не цитирует; P2 и P3 сохраняют 31–32 % (P2: 24 из 77), P6 — 81 % (42 из 52, самый длинный сценарий, 258 слов).
- В режиме транскрипта модель принимает меньше фактов (P2 и P4: ноль): сборка при этом доступна (ответы по сути), но «Я понял так…» в P2 и P4 так и не предложено: итоговое действие (`suggest_take`) модель не назвала.

## Что осталось

- Одного прогона на режим недостаточно для вывода об улучшении: разница по режимам, шум модели не измерен. Письменный режим с E2/E3 не перемерен.
- Решение 2 по E2 (проверка и повторная попытка при низкой доле фраз автора) не реализовано; доля сохранения 45–48 % остаётся ниже половины.
- Ошибки распознавания исправляются моделью по смыслу; ошибок, которые меняют смысл, симулятор не создаёт (замены гласных и окончаний), на настоящих записях Whisper это не проверялось.
- Остаточный риск E6: длинные ответы из общих слов (3 из 10 синтетических) считаются материалом.
- Токены: прогон 3 — 233 176 (лимит задачи 300 тыс. не превышен). За 09.10 всего 926 539 (до этой задачи 693 363) — **дневной лимит 500 тыс. превышен по разрешению владельца на запуск**. Нарастающим итогом с 08.10: 1 575 034.
