## Сделано

1. **Общее поведение оверлеев** — `dialog-behavior.ts` (`useDialogBehavior`): Esc, фокус-ловушка Tab (через уже существующие `getSheetFocusableElements`/`trapSheetTab`), начальный фокус внутри, возврат фокуса на триггер. Им пользуются `VocalModal`, `Sheet`, `ActionSheet`, `ConfirmAlert`.
2. **Новые компоненты:** `Sheet` (нижний лист с ручкой, клик по фону закрывает, фон вне порядка Tab), `ActionSheet`, `ConfirmAlert` (начальный фокус на безопасном ответе «Отмена»), `Chip` (нажатое состояние, съёмный с именованной кнопкой ×), `MonthCalendar` (сетка, сегодня, точки, выбранный день, сброс только при заданном фильтре), `IosNavBar` (44 px под safe area, «Назад», малый заголовок появляется при прокрутке).
3. **Перенос на токены P1:** `ActionButton`, `IconButton`, `Panel`, `Composer` (одна кнопка: микрофон при пустом поле, стрелка при тексте, подсказка под полем), `SegmentedTabs` (текстовый и иконочный варианты 36×28 с подсказкой и зоной нажатия 44 px), `StatusBadge` (точка цвета статуса + подпись), `ProgressBar` (пороги по цвету), `VocalModal`.
4. **Каталог `/dev/ui`** показывает новый набор и открывает все четыре оверлея; в продакшене по-прежнему `notFound()`.
