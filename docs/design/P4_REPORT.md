# P4 — мобильная версия (iOS, ≤ 640 px; работает на всех touch-ширинах ниже shell-брейкпоинта)

Ветка `feat/p4-mobile` от `feat/p3b-takes`. Логика диалога, сценария, дублей и записи не менялась: те же endpoints, те же DTO.
Скриншоты 390×844 (DPR 2): `docs/design/p4-after/`.

## Что сделано

| Область | Решение |
|---|---|
| Экран мысли | `IosNavBar` («‹ Мысли», «…»), заголовок крупный и сворачивается в бар при прокрутке (IntersectionObserver); статус; `SegmentedTabs` на всю ширину. Глобальная шапка и бургер на странице мысли скрыты. |
| Диалог | колонка фиксированной высоты: лента прокручивается внутри, композер и чипы («Не помню», «Пропустить вопрос», «Собрать сценарий», «Записать дубль») прижаты к низу; `--kb` из `visualViewport` поднимает композер над клавиатурой, таб-бар на время клавиатуры скрыт. Подсказка — только под последним вопросом. |
| Сценарий | одна колонка: версии — «пилюли» с горизонтальной прокруткой, ридер Literata 19/1.65, «Что изменено» свёрнуто, «Копировать»/«Скачать» иконками; нижняя панель: «Собрать новую версию» (primary), «Править», «…» → ActionSheet («Сделать итоговым», «Помочь со сценарием»). |
| Путь дублей (ref 08) | фокус-карточка дубля (итоговый или последний): цитата/видео-кадр, «Слушать / Читать / Видео», «Сделать итоговым»; ниже вертикальный таймлайн остальных дублей, тап переносит фокус; «от последнего / от первого»; призрак «Следующий дубль · Записать»; облачко, вывод и стикеры «Что улучшить» — только при сохранённых данных. |
| Листы | `VocalModal` и `Sheet` — нижние листы с ручкой; меню дубля, действия мысли, «ещё» сценария — `ActionSheet`; удаление — `ConfirmAlert`. |
| Safe-area / клавиатура | `env(safe-area-inset-*)` на таб-баре, навбаре, панели действий; `--tabbar-h`, `--bottom-chrome`, `--kb` в `globals.css`. |
| Нажатия | `@media (hover: none)`: press-состояние `:active` вместо hover; цели ≥ 44 px (чипы диалога, «выбрать», загрузка файла, заголовок «Загрузить видео…»). |

## Отличия и ограничения

- **Клавиатура проверена эмуляцией:** в headless Chromium `visualViewport` не уменьшить; тест выставляет `--kb: 336px` и `data-kb-open`, а чистая функция `keyboardInset` покрыта юнит-тестом. На реальном iOS Safari нужна проверка владельцем.
- **Поле композера:** `textarea` 36 px внутри «пилюли» ≥ 44 px (цель нажатия — вся пилюля).
- **Список мыслей и профиль** в P4 не переделывались (оставлены как есть: шапка, сетка карточек) — в задании перечислен экран мысли.
- **Горизонтальный таймлайн/peek** из ref 08 не делал: вертикальный таймлайн + фокус-карточка.
- **Таймкод-переход, `TakePlayer`, inline-редактор** прежнего мобильного списка заменены диалогами «Читать» (как на desktop); `TakeList`/`TakePlayer` остались в репозитории, но не используются.
- **Запись (RecordingView)** на мобильном — прежний вид, переработан только каркас (навбар).
- Изменены принятые тесты строк-проверок разметки: `s2-data-deletion` (удаление теперь через `DeleteTakeConfirm`/`DeleteThoughtConfirm`), `p3a-thought-desktop` (якоря мобильной ветки), `p3b-takes` (выбор компонента пути).
