# P5 — «Библиотека» (список мыслей, desktop и mobile)

Ветка `feat/p5-library` от `feat/p4-mobile`. Логика списка и API не менялись: тот же `buildArchiveListApiQuery`, `GET /api/reels`
(курсорная пагинация), `GET /api/reels/calendar`, `archive-preview`, то же URL-состояние (`q`, `status`, `sort`, `from`, `to`).
Скриншоты: `docs/design/p5-after/` (`1440x900_*`, `390x844_*`, DPR 2 на mobile). Источник: прототип `vocal-v0` (`thought-library.tsx`) и канон 09.

## Что сделано

| Область | Решение |
|---|---|
| Сайдбар (desktop) | логотип → «Мысли» → **СТАТУС** (иконки круг / полукруг / галочка + «Все») → **ДАТА** (`MonthCalendar` из P2) → «Профиль» → «Свернуть». При свёрнутом сайдбаре статус и календарь скрыты. |
| Календарь | `ArchiveCalendar` теперь — `MonthCalendar` над существующим `/api/reels/calendar`: точки на днях с мыслями (с теми же поиском и статусом), пресеты «Сегодня / Вчера / Неделя», «Весь месяц», «Сбросить», переключение месяцев. Пресеты и день превращаются в тот же диапазон `from`/`to` (`src/lib/library-date.ts`, чистые функции с тестом по трём часовым поясам). |
| Чип даты | над списком: «9 октября» / «Сентябрь 2026» / «Неделя» + «×» и число мыслей. |
| Тулбар | заголовок, поиск, «Новые / Старые», «+ Новая мысль», вторичный переключатель раскладки **Сетка (по умолчанию) · Стол · Список**. ⌘K не делался. |
| Раскладки | **Сетка** — вертикальные полароиды 3:4 (бумага `--paper*`, название Literata, статус-иконка), колонки `auto-fill, minmax(200px, 1fr)`. «Стол» — прежние развороты, «Список» — строки. Выбор помнится в `localStorage` (ключ прежний, по умолчанию теперь «Сетка»). |
| Карточка | **«i» открывает предпросмотр, вся остальная карточка — одна ссылка в мысль.** То же в «Списке»: строка ведёт в мысль, «i» — предпросмотр. |
| Предпросмотр | прежний `ArchiveThoughtPreview`: сценарий, версия, число дублей, «Снять новый дубль», «Перейти к работе с мыслью». |
| Mobile | шапка в два ряда («Мысли» + «Дата»; поиск + сортировка), статусы — горизонтальная лента чипов, «На столе сейчас» (лента мини-полароидов, пока нет фильтров) и «Все мысли» строками: мини-полароид, название, одна строка меты «статус · N дублей · дата», «i» 44 px. Календарь — нижний лист. |
| Таб-бар | «Мысли / mic / Профиль», safe-area; mic открывает «Новая мысль» (на странице мысли таб-бар прежний, из двух вкладок). Глобальная шапка с бургером на списке скрыта. |
| Пустые состояния | «Запишите первую мысль» (мыслей нет, микрофон-кнопка) и «Ничего не найдено» + «Сбросить фильтры» (поиск, статус и дата сбрасываются вместе). |
| Подгрузка | прежняя: `IntersectionObserver` + «Загрузить ещё», повтор при ошибке следующей порции. |

## Отличия и ограничения

- Из канона 09 заменено решением владельца: на mobile не сетка 3 в ряд, а лента «На столе сейчас» + строки; предпросмотр по «i», а не по верхней зоне карточки.
- Прежние `ArchiveDateControl` (выпадашка даты в сайдбаре) удалён; старые «Показать месяц» и ручная сетка календаря заменены `MonthCalendar`.
- Ресурс/квота (`ResourceMeter`, баннеры) из прототипа не переносились: это отдельный backend-этап.
- В «Списке» на desktop мета — дата и статус (как раньше); число версий в списковом DTO нет, поэтому в строках mobile показано число дублей.
- Принятые разметочные тесты обновлены осознанно: `p01-2`, `p01-3`, `p01-4`, `p01-5`, `p01-6-0`, `p01-6-2-desktop-static`, `p01-6-2-final`, `p17-visual`, `thought-preview` (новые тексты, якоря и поведение «i»).
