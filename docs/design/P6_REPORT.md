# P6 — состояния, профиль, запись, вход (отчёт)

Ветка `feat/p6-states-profile` от `feat/p5-library`. Логика и API не менялись; оплата и «ресурс» не делались.

## Что сделано
1. **Профиль (07)** — `ProfileScreen`: портрет (Literata 18/1.65, `Portrait reading`) слева, карточка аккаунта справа (ниже на mobile): почта, квота — только при `quota.enforced && !exempt` (иначе блока нет), «Выйти», красная «Удалить аккаунт» → `ConfirmAlert` («Все ваши мысли, дубли и сценарии будут удалены…»). «Дополнить о себе» открывает существующий `ProfileConversation` в `VocalModal` (диалог на desktop, нижний лист на touch). Mobile: `IosNavBar` «‹ Мысли».
2. **Настройки** — экрана настроек в продукте нет (`/settings` — редирект на список мыслей), поэтому строки «Настройки» нет и экран не придумывался.
3. **Запись на mobile** — полноэкранный телесуфлёр (Literata 22), круглая «Начать запись» 80 px над safe-area, во время записи таймер (tabular), волна по уровню, красный «Стоп», «Отмена» → существующее подтверждение. Микрофон запрашивается только по нажатию. Ошибка микрофона/сохранения — `InlineError` с «Повторить».
4. **Состояния** — `ShellLoading` = скелетоны (`list`/`thought`/`page`, `loading.tsx` для `/reels`, `/reels/[id]`, `/profile`); `ShellError` = `InlineError` + «Повторить»; `ShellEmpty` = `EmptyState` (404 со ссылкой «К мыслям»); разрозненные `text-bad` в панелях дублей/сценария/вопросов заменены на `InlineError`.
5. **Вход** — одна карточка (`Panel`, desktop), полноэкранно с safe-area (mobile), `Field`, primary `ActionButton`, `InlineError`; тексты прежние.

## Вне переноса
Лендинг уже сделан (`4ac2863`, `51c6582`) и в перенос не входит. Оплата и «ресурс» ждут бэкенда.

## Состояния, которых нет как события (не придумывались)
- Экран настроек.
- Отдельное «нет сети»: ошибки сети приходят как текст ошибки запроса, отдельного состояния/детектора offline нет.
- Отдельный экран «нет доступа к микрофону» — есть текст `microphonePermissionMessage` в `InlineError`.
- AI_BUSY 503 показывается текстом сервера (`usage-guard.ts`) через существующие `InlineError` диалога; отдельного компонента не заведено.
