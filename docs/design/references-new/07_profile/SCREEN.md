# 07 — Профиль (desktop)

**Окно / заголовок:** Vocal · Профиль

## О чём этот экран

Большая страница **портрета автора** — биография от третьего лица (как пишет писатель о писателе): что любит, жизненные события, важное, зачем блог. Одна primary-кнопка **«Дополнить о себе»** открывает диалог Q&A для дополнений.

## Что делает пользователь

- Читает портрет-биографию.
- Нажимает **«Дополнить о себе»** (диалог дополнений).
- Переключается на **Мысли**.

## Чего нет на этом экране

- Чипов целей / границ + чата как основного UI.
- Плотных форм-настроек и тумблеров.
- Записи дублей и пути дублей.
