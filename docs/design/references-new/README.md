# Vocal — редизайн (референс)

Дата: 15 сентября 2026.  
Палитра: **мягкая фиолетовая студия** (`#0B0714` / `#1A1228`, акцент `#8B7CFF` / `#C4B5FD`).  
Шрифты: Inter — интерфейс; Literata — мысль внутри полароида; Caveat — мелкие подписи полароида.

## Утверждённые экраны

| № | Экран | Папка | Статус |
|---|---|---|---|
| 01 | Путь дублей (desktop) | `01_takes_path/` | **утверждён** (не трогать) |
| 02 | Запись + телесуфлёр | `02_recording/` | **пересмотрен** — script LARGE / stage SMALL |
| 03 | Прежний список мыслей | `03_thoughts_list/` | **заменён экраном 09**; хранится для истории прежней композиции |
| 04 | Новая мысль | `04_new_thought/` | **пересмотрен** — one card, no tabs |
| 05 | Диалог с Vocal | `05_dialog/` | **пересмотрен** — large script, compact chat |
| 06 | Сценарий | `06_script/` | **пересмотрен** — visible «Редактировать» |
| 07 | Профиль | `07_profile/` | **пересмотрен** — writer bio portrait |
| 08 | Путь дублей (mobile) | `08_mobile_takes/` | **пересмотрен** — focus card + timeline, not zigzag |
| 09 | Архив мыслей desktop/mobile | `09_thoughts_archive/` | **актуальный** — calendar filter, lazy grid, preview/dialog hit areas |

Правила продукта (не ломать): статусы Не завершена / В работе / Успешно завершена; итоговый дубль и итоговый сценарий выбираются независимо; запись только после «Начать запись»; при записи диалога ИИ нет; сравнение дублей делает модель сама; на дубле только replay / читать / открыть видео.  
Навигация: **Мысли** + **Профиль**.
