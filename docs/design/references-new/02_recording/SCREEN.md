# 02 — Запись дубля (desktop)

**Окно / заголовок:** Vocal · Запись дубля 5

## О чём этот экран

Сцена записи нового дубля с **обратными пропорциями**: большой сценарий (телесуфлёр) — главная зона чтения; компактная полоса камеры/мика справа с крупной кнопкой «Начать запись». Диалога с ИИ нет. Запись ещё не началась.

## Что делает пользователь

- Читает сценарий крупным шрифтом (телесуфлёр).
- Нажимает большую кнопку **«Начать запись»** (запись стартует только после этого).
- Скрывает панель сценария кнопкой **«Скрыть»** (по умолчанию панель видна и доминирует).
- Переключает камеру / микрофон.
- Возвращается к пути дублей («← К пути»).

## Чего нет на этом экране

- Диалога с ИИ.
- Сравнения дублей вручную.
- Редактирования сценария на месте.
- Большой сцены превью как в CapCut — превью компактное.

## Композиция (ревью 15.09.2026)

- Слева (~70%): крупный сценарий Literata ~28px.
- Справа (~300px): маленький viewport + «Начать запись».
