# 04 — Новая мысль (desktop modal)

**Окно / заголовок:** Новая мысль

## О чём этот экран

Модальное окно поверх списка мыслей. **Одна карточка** без вкладок: микрофон (приглашение записать голосом), текстовое поле, кнопка загрузки видео.

## Что делает пользователь

- Нажимает круглую кнопку микрофона, чтобы записать голосом (запись только после явного действия).
- Или пишет мысль в текстовое поле.
- Или выбирает **Видео** (иконка-кнопка).
- Создаёт мысль / отменяет.

## Чего нет на этом экране

- Вкладок **Текст | Голос | Видео**.
- Фильтров и табов формата.
- Диалога с ИИ во время записи.
- Автостарта записи без кнопки.
