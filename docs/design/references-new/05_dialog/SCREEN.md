# 05 — Диалог с Vocal (desktop)

**Окно / заголовок:** Vocal · Диалог

## О чём этот экран

Большая колонка **сценария для чтения** слева; справа — **компактный** тред чата. Выбор дубля на этом экране недоступен. Это не экран записи.

## Что делает пользователь

- Читает сценарий крупным Literata.
- Пишет в компактный чат или выбирает chip.
- Отправляет голос / видео через композер.
- Возвращается к пути дублей.

## Чего нет на этом экране

- Выбора / селектора дублей (take selection).
- Полноэкранной записи дубля.
- Широкого чата как у Claude на весь экран — чат узкий (~380px).
- Таблицы сравнения дублей — сравнение делает модель в разговоре.
