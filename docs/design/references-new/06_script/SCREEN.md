# 06 — Сценарий (desktop)

**Окно / заголовок:** Vocal · Сценарий

## О чём этот экран

Версии сценария слева, справа — текст выбранной версии. Видимая кнопка **«Редактировать»** (в топбаре и у ридера). Также: «Помочь со сценарием», «Сделать итоговым». Итоговый сценарий независим от итогового дубля.

## Что делает пользователь

- Листает версии сценария.
- Нажимает **«Редактировать»**.
- Нажимает **«Сделать итоговым»**.
- Вторично: **«Помочь со сценарием»**.

## Чего нет на этом экране

- Привязки «итоговый сценарий = итоговый дубль».
- Записи и чата как основного содержимого.
