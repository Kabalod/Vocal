# 03 — Список мыслей (desktop)

**Окно / заголовок:** Vocal · Мысли

## О чём этот экран

Главный список мыслей в master-detail: **широкий** список слева, превью справа. Фильтры статусов — в **левом сайдбаре** (не чипы в топбаре). В превью — увеличенный полароид и блок **оценки ИИ по всему пути** дублей.

## Что делает пользователь

- Фильтрует в сайдбаре: **Все / Не завершена / В работе / Успешно завершена**.
- Выбирает мысль в широком списке и смотрит превью.
- Читает вердикт ИИ по всем попыткам («Оценка по пути»).
- Создаёт мысль кнопкой **«Новая мысль»**.
- Открывает путь / диалог / сценарий; переходит в **Профиль**.

## Чего нет на этом экране

- Фильтров-чипов в верхнем хроме.
- Инструкционного текста в хроме.
- Записи дубля и чата ИИ на этом экране.

## Композиция

- Sidebar ~200px: Vocal + фильтры + навигация Мысли/Профиль.
- Список ~540px (шире прежнего).
- Превью: большой полароид (~200px) + AI assessment block.
