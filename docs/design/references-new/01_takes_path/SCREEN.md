# 01 — Путь дублей (desktop)

**Окно / заголовок:** Vocal · Разбор · Дубли  
**Название на экране:** Путь дублей — «как рассказать о проекте»

## О чём этот экран

Карта попыток внутри одной мысли. Автор видит, как дубли идут по времени, что ИИ вынес из каждого и как мысль менялась. Это не таблица и не чат: это путь.

## Что делает пользователь

- Переслушивает / перечитывает / открывает видео дубля (полароид).
- Смотрит вердикт ИИ в облачке и короткий вывод под карточкой.
- Читает советы на пути (sticky между дублями) — их пишет модель, не автор.
- Переключает порядок: **от последнего** (по умолчанию) или **от первого**.
- Создаёт новый дубль кнопкой «+ Новый дубль».

## Чего нет на этом экране

- Ручного выбора «сравнить дубль A с B» — сравнение делает ИИ.
- Диалога с моделью (диалог — отдельный экран; при записи его нет).
- Редактирования сценария.

## Композиция (утверждена 15.09.2026)

- Шахматный зигзаг: 1 слева → 2 справа → 3 слева → 4 справа.
- Пунктир — **плавная S-кривая**, не ломаные отрезки.
- Расстояния органичные, не равная сетка: больше воздуха, лёгкий наклон полароидов.
- По умолчанию: **последний дубль сверху слева**, старые ниже по карте.

## Полароид

- Кремовая рамка, толстый низ.
- Квадрат: **кадр видео**, если был ролик; иначе **текст основной мысли**.
- На рамке: «Дубль N · длительность».
- Сверху облачко ИИ («стало ближе к советам» / «мысль сдвинулась»).
- На кривой — бумажные sticky «что улучшить».
- Итоговый дубль — штамп «итоговый».
