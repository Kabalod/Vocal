# Инвентарь — hadunkin

- дата: 20-Aug-2026
- сырьё: `Analyz/hadunkin/*.txt`
- правило: один файл на Instagram-id, берём более длинную транскрипцию

## Цифры

| | |
|---|---|
| файлов txt | 505 |
| уникальных id | 440 |
| пригодных (не кредит, не пустышка) | 365 |
| кредиты STT / мусор | часть из 440, отсечена |
| медиана по сырью | ~72 слова |
| клипов <80 слов | много; пилот отдельно проверяет микро |
| 200+ слов | мало, порядка 15 уникальных |

## Типы, которые корпус реально содержит

- улица / социальный эксперимент
- сенсорный влог и процесс («записываю по пути»)
- короткий talking-head / состояние
- мысль (80+ слов)
- диалог с прохожим
- STT-мусор (`DimaTorzok`, титры)

Полный Prompt 1 на 40-словной улице почти всегда выдумывает тезис. Поэтому классификация типа — обязательный шаг перед смыслом.

## Дубли

Один и тот же ролик может лежать двумя транскрипциями (разное время). Примеры в пилоте: `Da8twZLOvvr`, `DcEydt6utBT`. В результатах один id.

Похожие тексты с разными id тоже бывают (повтор выкладки). В пилоте не дублировали: «не делюсь идеями» — только `DVt-mPoDPv2`, не `DWzcxSguM86`.

## Что не вошло в пилот

Длинные диалоги (`DTkvws0jG13`, `DQg6ganDCmL`), сериал «Разделение», продажи в блоге, чаепития-анонсы. Их лучше брать на полном проходе как отдельные типы.
