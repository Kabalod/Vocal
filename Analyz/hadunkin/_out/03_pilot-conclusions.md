## Что сработало

1. **Тип ролика важнее длины.** 106 слов «не делись идеями» (`DVt-mPoDPv2`) дали полный смысл и мышление. 216 слов гляделок — тоже, потому что в конце появился тезис. 173 слова «гладкой версии» — мысль есть, но без кейса она ближе к речи.
2. **Лучший ход автора в пилоте — переворот очевидной морали.** Метро не стало «пробивайся». Гляделки не стали «я победил». «Не делись» не про кражу. «Всё сказано» не про сдаться.
3. **Поле кормит мысль.** Столб, эскалатор, гляделки, забытый микрофон. Где нет поля (`DT5K9WejLeB`, `DY5YFh1uf_k`) — либо проповедь, либо мантра.
4. **Микро честно ломают Prompt 1.** Состояние `DVt8hZzDvBo` и процесс `DPtfVrqjMpd` нельзя декомпозировать «как ролик с архитектурой». Усечённый смысл + механика жеста — правильный потолок.

## Где промпты врут, если не остановить

- На аффирмации достроят «карту мысли» из синонимов.
- На процессе достроят философию ежедневности, которой в тексте нет — есть только жест.
- На эксперименте достроят глубокий инсайт, хотя текст может быть отчётом с мягким закрытием («так должно было быть»).
- Prompt 3 без права сказать «не применялся» выдумает генеративный принцип из лозунга.

## Что брать в этап 3 (полный смысл)

Приоритет: уникальные id с ~80+ слов, где есть «я заметил / ситуация / что если», не только «делайте».  
Не приоритет: повторные анонсы чая, кредиты, дубли текста.
