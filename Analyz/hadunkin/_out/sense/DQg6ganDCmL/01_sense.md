# Prompt 1 — Смысл

Навигация: [смысл](../index.md) · [мета](00_meta.md)

### 1. Центральная мысль
После привета фаната: внутри уже есть всё нужное, но он познаёт через крайности (полгода без денег; неделя без стимулов ради одиночества; первый шаг из социофобии — знакомства). Первые четверо боялись его сильнее. Вибрации / чувствуем других. Внешнее не случайно: строил внутренний мир — видно снаружи. Стройте внутри, снаружи станет таким же.

Тема: крайности / внутренний мир. Тезис: знание через перегиб; внешнее следует за собранным внутри.

### 2. Исходный вопрос
Почему мне нужны крайности, чтобы понять простое — и откуда «снаружи»?

### 3. Карта мысли
1. Привет (рамка). 2. Всё уже внутри, путь через край (тезис). 3. Деньги / одиночество / социофобия (примеры). 4. Они боялись больше (поворот). 5. Внутри → снаружи (вывод).

### 4. Аргументация
Три личных эксперимента + сцена первых четверых. Сосед внимания `DQUHj4ZjNsp`.

### 5–6.
улица → плотная мысль. Обещание «внутри всё есть» закрыто правилом внешнего.

### 7. Ядро
я познаю это через крайности. …Давайте строить свой внутренний мир. И он обязательно построится снаружи нас.

### 8. Неопределённость
«Всё не просто так» — риторика; держать крайности и зеркало внутри/снаружи.
