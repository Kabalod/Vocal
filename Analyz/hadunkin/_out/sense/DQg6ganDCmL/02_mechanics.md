# Prompt 2 — Механика

Навигация: [механика](../index-mechanics.md) · [транскрипт](00_transcript.md)

### Hook
Механизм: встреча фаната (сегодня смотрела) → отрезок «пока» → тезис «внутри уже всё есть».

Почему продолжить после улицы: обещание, *как* он это познаёт (крайности).

### Удержание
- три эксперимента: деньги / одиночество / социофобия
- поворот: первые четверо боялись его сильнее
- вибрации (слабая опора)
- внутренний мир виден снаружи
- призыв строить внутри

### Конкретность
Сильны три срока (полгода, неделя, первый шаг).  
«Всё не просто так» и «вибрации» — абстрактный клей. Улица к тезису не обязательна, но даёт «меня видят».

### Риторические приёмы
- правило трёх крайностей
- инверсия страха (они боятся больше)
- зеркало внутри/снаружи
- обращение «давайте»

### Плотность
Три кейса нельзя сжать в один — это доказательство метода.  
«Вибрации» можно без потери тезиса про крайности.

### Голос
После бытового привета — уверенный рассказчик опыта, в финале проповедь.

### Signature (гипотеза)
Познание через перегиб + зеркало внутреннего. Не склеивать улицу фаната с тезисом как «доказательство», это рамка дня.
