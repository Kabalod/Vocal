# Prompt 1 — Смысл

### 1. Центральная мысль
Сходил на экскурсию впервые за 20 лет «всковырнуть травму детства» — спойлер: прикольно. Час молчать, меценаты, фонд «Помощь рядом», округление Яндекса. Из мысли: мотивы дающих разные (пример / нет смысла в состоянии / отмыть имя / необъятная душа).

Тема: экскурсия. Цельного тезиса нет. Не строить архитектуру вокруг рекламы фонда.

### 2. Исходный вопрос
Что будет, если через 20 лет снова пойти на экскурсию? — закрыто «прикольно», без разбора травмы.

### 3. Карта мысли
1. Травма / экскурсия (обещание). 2. Отчёт + титры фонда (процесс). 3. Мотивы меценатов списком (наблюдение, не вывод).

### 4. Аргументация
Список мотивов без опоры. Травма не раскрыта.

### 5–6.
обещание травмы не выполнено. Хвост — интеграция.

### 7. Ядро
кто-то подавал пример. Кто-то не видел смысла в своем состоянии. Кто-то отмывал свое имя. А у кого-то была просто необъятная душа.

### 8. Неопределённость
Prompt 2 не применять. «Травма детства» — ярлык без содержания.
