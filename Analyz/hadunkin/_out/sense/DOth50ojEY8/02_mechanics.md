# Prompt 2 — Механика

- автор: hadunkin_art · id: DOth50ojEY8 · тип: мысль / кейс · вход: [смысл](01_sense.md) · этап: механика / пачка 3 · статус: выполнен

Навигация: [механика](../index-mechanics.md) · [транскрипт](00_transcript.md)

Тезис слабее рассказа продукта. Prompt 2 по кейсу продажи, не по философии состояния как доказанной.

### Hook
Механизм: конкретный результат + поправка («первая продажа… ещё не прошла, но офигеть»).

Почему продолжить: редкое событие блога; статус сделки открыт — незавершённость.

### Удержание
- три месяца назад: дикий страх, ответственность, отписки у других
- шагнул: ценность / помогло бы раньше
- эволюция: вебинар → через день чат, созвоны, рефлексия
- второй проект после «Крика» — объединение, состояние
- вывод: выровняв состояние, стабильно создавать, «невозможно проиграть»
- «как-то так»

### Конкретность
Срок три месяца, смена формата за день — якоря. Сделка «прошла / напомню» мутная. «Невозможно проиграть» не подкреплено.

### Риторические приёмы
- новость с оговоркой
- чужой страх ниши как фон
- мотив «себе прошлому»
- скачок рассказ продукта → ценностный финал
- сброс «как-то так»

### Плотность
Нельзя выкинуть страх и смену вебинар→чат.  
Финал про состояние можно сжать: ролик держит история формата, не лозунг непроигрыша.

### Голос
Восторженный отчёт, затем объясняющий продукт, в конце категоричный сверх меры кейса.

### Signature (гипотеза)
Новость дня обрастает группой поддержки. Не читать финал как доказанную модель — эйфория продажи в тексте не снята.
