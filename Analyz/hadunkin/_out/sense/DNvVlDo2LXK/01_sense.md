# Prompt 1 — Смысл

### 1. Центральная мысль
Сравнивает себя с собой, не с другими. В кадре: просит прохожего подержать камеру, даёт комплимент — раньше не мог. ~100 дней преодоления, день 112/113, сбился со счёта; ежедневное тоже результат. Сравнение с собой — шанс замечать и искренне радоваться своему, не чужому.

Тема: сравнение. Тезис: единственный рабочий эталон — свой прошлый «не мог».

### 2. Исходный вопрос
С кем сравниваться, чтобы радоваться результату, а не съедать его?

### 3. Карта мысли
1. Сегодня сравниваю с собой (тезис). 2. Просьба камеры / комплимент как доказательство сдвига (пример). 3. Сотня дней, сбился — всё равно результат (уточнение). 4. Сравнивайте с собой (вывод).

### 4. Аргументация
Поле + самоотчёт серии. Сосед «сравнение убивает 1–3 шаг»: `DQW4mnSjMMD`.

### 5–6.
тезис → улица как доказательство. Обещание закрыто жестами, не цифрой дня.

### 7. Ядро
Сегодня я сравниваю себя не с кем-то, а с самим собой. …Сравнивайте себя с самими собими. …единственный шанс… радоваться искренне своим результатам.

### 8. Неопределённость
«Сбился с пути» может быть счёт дней, не срыв — не додумывать срыв.
