# Prompt 2 — Механика

### Hook
Механизм: неожиданное утверждение («меня можно было просто напугать») + формула дворника.

Почему продолжить: детский испуг как универсальный мотор; ждём, куда он сращен сейчас.

### Удержание
- бежать без инструкций
- сращивание с нынешними «надо»
- тройка: расти / зарабатывать / безопасность
- «вроде бы рациональная»
- источник: страх, который почти нельзя отпустить
- нет совета «отпусти»

### Конкретность
Формула дворника конкретна как речь. Сцены «мне так сказали» нет — «оказывается, можно было». Нынешние «надо» — список без кейса работы.

### Риторические приёмы
- генеалогия мотива
- повтор «надо же»
- контраст рациональный вид / топливо страха
- открытый конец на невозможности отпустить

### Плотность
Почти нельзя выкинуть. «Нестись без оглядки» и «пуще огня» — один удар, для ритма оба.

### Голос
Исследующий, уязвимый, без инструкции. Сильный кандидат Prompt 3: обычно считают расчёт, он видит испуг.

### Signature (гипотеза)
Взрослая гонка = старый страх в новой одежде. Не путать с визиткой грузчика `DSQgbXCDBcr`.
