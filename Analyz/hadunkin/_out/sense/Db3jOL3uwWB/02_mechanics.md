Стоп без «просто делай». Полный Prompt 2 обязателен — иначе сольётся с ядром кластера.

### Hook
Механизм: техническая авария («сломал микрофон… придётся кричать») → заявленная тема дня.

Почему продолжить: помеха кадра как напряжение; мысль обещана как «сложно, когда нет зачем».

### Удержание
- нет зачем / нет смысла менять
- перечень: неудобно, неприятно, не так, хотелось бы иначе
- «жизнь так устроена»
- железобетон установок
- сил на «иначе» не выделяется
- «самое сложное состояние» — срез, не рецепт

### Конкретность
Микрофон — рамка. Бетон установок — метафора без объекта (какая установка). Нет завтрашнего снятия.

### Риторические приёмы
- помеха техники как метафора усилия быть слышным
- повтор «да,…»
- метафора железобетона
- отказ от императива кластера

### Плотность
Ядро: тяжёлое не дискомфорт, а бетон, из которого нет силы на другой ход.  
Рамка микрофона съёмна для смысла, не для голоса ролика.

### Голос
Громкий по необходимости, исследующий, без инструкции. Честный обрыв.

### Signature (гипотеза)
Зафиксировать стоп и не лечить лозунгом. Сосед дыры бегства, не сосед «делай из апатии».
