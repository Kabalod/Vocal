Не вариация «просто делай»: топливо названо. Полный Prompt 2 уместен.

### Hook
Механизм: вопрос без ответа («когда остановлюсь / где грань»).

Почему продолжить: частый вопрос зрителя, автор сразу честен «сам не знаю».

### Удержание
- страх не реализоваться / бросить не закончив
- нет предела и конца
- повышение ставок: бросить = умереть в канале
- парадокс: конца не знает
- закрытие словом «парадокс», не советом

### Конкретность
Нет сцены конкретного дня. Всё — самонаблюдение мотива.  
Сильна формула ставки, слаба эмпирика «когда чуть не бросил».

### Риторические приёмы
- открытый вопрос
- повтор страх / конец / бросить
- гипербола смерти в канале
- называние жанра («парадокс») как точка

### Плотность
Почти нельзя выкинуть. Синонимы «предел / конец» оставляют ритм.

### Голос
Исследующий, уязвимый, без инструкции. Редкий ролик кластера без императива.

### Signature (гипотеза)
Честный мотив дисциплины вместо лозунга. Для Prompt 3 высокий приоритет.
