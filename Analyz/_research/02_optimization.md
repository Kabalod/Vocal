# Оптимизация процесса и промптов

- дата: 20-Aug-2026
- зачем: полный проход hadunkin был правильным *один раз* (калибровка метода). Повторять его на каждом авторе — расточительно.
- рядом: [разбор метода](01_method-review.md) · [промпты](../prompts_analysis_bloggers.md)

Полный проход hadunkin — калибровка. Дальше: [`03_protocol-v2.md`](03_protocol-v2.md) (контрастный автор, H1–H5, saturation, Author Model). Числа 40–80 / 15–30 / 12–25 — бюджетный ориентир, не закон; остановка по saturation.

## 1. Где ушли время и токены

Грубая воронка hadunkin:

| шаг | сколько единиц | стоимость одной | зачем было |
|-----|----------------|-----------------|------------|
| инвентарь | 505 → 365 | дёшево (скрипт) | обязательно |
| полный Prompt 1 | ~195 | дорого (8 разделов) | поймать контрходы к слогану |
| полный Prompt 2 | 52 + кластер | средне | только после тезиса |
| полный Prompt 3 | 40 | дорого | только после своего вывода |
| навигация, пачки, индексы | постоянно | скрыто дорого | без них база мертва |

Что было лишним *относительно цели «понять автора»*:

- Полный Prompt 1 на вариациях одного ядра («делай в состоянии»), когда вход уже можно было свести в таблицу кластера.
- Prompt 2 на тезисах, которые Prompt 3 всё равно не получил бы (нет своего вывода).
- Поздние дубли текста: второй разбор ловили руками, не скриптом.
- Повторное чтение транскрипта на каждом слое: Prompt 2/3 должны опираться на смысл + короткие цитаты, не на полный STT заново, кроме спорных мест.
- Обновление индексов вручную после каждой пачки — нужно, но схема папки должна быть шаблоном, не изобретением.

Полный каталог 80+ окупился тем, что слоган отделился от мышления. Для **второго** автора это уже не надо доказывать тем же объёмом, если есть дешёвый шлюз.

## 2. Как оптимизировать процесс (воронка)

Цель: те же открытия, меньше полных промптов.

```
скрипт: id, слова, дубль текста, кредит STT, грубый тип
        ↓
Prompt 0 (шлюз, ~8 строк) на всех пригодных
        ↓
пилот 8–12 смешанных типов × Prompt 1–3  → калибровка порога и вранья
        ↓
полный Prompt 1 только: уникальный тезис | представитель кластера | контрход
        ↓
кластер, как только ядро повторилось 3 раза
        ↓
Prompt 2: представители + контрходы + плотные одиночки
        ↓
Prompt 3: только свой вывод (не сцена, не мантра, не «просто начни»)
        ↓
сверка гипотез + адвокат дьявола (поиск опровержений)
```

Ориентир на следующего автора (не догма):

| слой | hadunkin было | целевой порядок |
|------|----------------|-----------------|
| шлюз | не было | все пригодные |
| полный смысл | 195 | 40–80 |
| механика | 52 | 15–30 |
| мышление | 40 | 12–25 |
| кластеры | 1 поздний | с 3-го повтора, сразу |

Правило остановки полного Prompt 1: если 15 подряд роликов либо кластер, либо «тезиса нет» — не добивать хвост каталога, пока адвокат дьявола не попросит искать контрход.

Пачки: лучше **12–16** полных разборов и сразу «какие тезисы повторились», чем 24 смысла без кластера.

Не экономить на: пилоте, неопределённости, контрходах, дублях, праве «не применялся».

## 3. Как улучшить процесс (не только урезать)

1. **Шлюз до смысла.** Тип + «тезис есть / тонок / нет» + одна фраза + «похоже на id …». Это и есть 80% фильтра, который мы делали головой на 195 файлах.
2. **Кластер как рабочий объект**, не постфактум. Таблица: id / вход / сверх ядра / опора. Вариации не получают полный Prompt 2.
3. **Канон компактного Prompt 1 с пачки 1**, не с пачки 5. Восемь заголовков оставить, ответы — короткие. Длинный канон нужен только пилоту (калибровка).
4. **Один файл ролика — три слоя по мере допуска**, не три прохода по всему корпусу. Смысл пачки → сразу 2–3 механики на плотных, не копить 195 без единого 02.
5. **Адвокат дьявола** после первой гипотезы («автор = X»): 10 роликов искать опровержение. У hadunkin это должно было случиться после пачки 1, не после 195.
6. **Шаблон папки и индекс** (meta, transcript, sense, status) завести до пилота. Навигация не должна быть творческой работой.
7. **Скрипт дублей** (нормализация текста, порог похожести) до любой модели.
8. **Не смешивать Vocal-шкалу** с этим контуром. Отдельный пайплайн, отдельные файлы.

Минимальный проход, если бюджет жёсткий: пилот 12 → шлюз всех → полный Prompt 1 на ~40 плотных → 15 механик → 12 мышлений → сводка. Полный 80+ — только если на пилоте уже видно повторяющееся ядро, которое надо отличить от контрходов.

## 4. Как улучшить промпты

Не раздувать. Добавить **шлюз** и точечные стоп-строки. Оценка и советы по-прежнему запрещены.

### Prompt 0 — шлюз (новый)

Короткий, на каждый пригодный id:

- тип: мысль / улица→мысль / процесс / состояние / диалог / мантра / реклама / мусор STT
- решение: полный Prompt 1 / усечённый / не применять
- тезис одним предложением или `нет в тексте`
- если тезис есть: это повтор ядра `…` / контрход к `…` / одиночка
- дубль текста: `нет` / `см. id`
- 1 цитата автора (ядро) или `нет`

Запрет: не строить карту из 8 пунктов. Не выдумывать тезис из жеста.

### Prompt 1 — правки

В самое начало, до «центральной мысли»:

- тип и решение (полный / усечён)
- если усечён: только «есть ли мысль», ядро 1–3 фраз, неопределённость — стоп

Усилить п. 1: если нельзя отличить тему от тезиса — `тезиса нет`, не писать остальные разделы.

В п. 4: для каждого утверждения одна строка `опора: класс`. Если всё «личное без сцены» — так и сказать, не раздувать.

В п. 7: только цитаты транскрипта, не пересказ аналитика.

В п. 8: обязательные вопросы: чего нет в тексте; не достраивать ли это в уже известный кластер.

После п. 8 — **допуск дальше**: `Prompt 2: да/нет` и `Prompt 3: да/нет/ещё рано` с одной причиной.

Компактный режим (после пилота): те же 8 заголовков, лимит на раздел (например 3–6 строк). Калибровочный режим: без лимита, только пилот.

### Prompt 2 — правки

На вход: смысл + 5–10 строк транскрипта (хук и финал), не обязательно весь STT.

Добавить:

- хор корпуса vs новый ход (формула, которая уже звучала)
- если ролик — вариация кластера: **не заполнять** полный Prompt 2, одна строка «вход = …, см. кластер»

Signature: всегда «гипотеза», плюс «проверить на id … / не склеивать с …».

Убрать соблазн карты удержания из 12 пунктов: 4–7 точек достаточно.

### Prompt 3 — правки

Явно: если в смысле нет своего вывода — файл `не применялся`, генеративный принцип **запрещён**.

Рядом с генеративным принципом: «чего в тексте нет — принцип шире ролика? да/нет».

Цепочка рассуждения: пропускать звенья, писать `нет в тексте`, не восстанавливать.

Вопросы редактора оставить: они дешевле советов и ближе к инструменту помощи автору.

Не просить «наиболее вероятную биографию». Только модель, которая могла привести к *этому* тексту.

### Общее для всех трёх

- Явный список типов, на которых полный промпт запрещён.
- `нет в тексте` как валидный ответ любого пункта.
- Не подмешивать просмотры/лайки в реконструкцию мысли (можно отдельным слоем продукта, не здесь).
- На выходе — стабильные заголовки (для поиска и индекса), не свободное эссе.

## 5. Что важное заметил на проходе

Это не портрет автора, а свойства **метода и корпуса**, которые легко пропустить.

1. **Повтор слогана ≠ повтор мысли.** Одинаковое «делай в состоянии» держится разными входами (горки, пустота, злость, скотч). Для автора важен вход; для экономии — кластер.
2. **Контрход ценнее десятой вариации.** Час не делать, бетон, страх как топливо — без них автор = карикатура. Их мало, их нельзя фильтровать шлюзом как «похоже на ядро».
3. **Длина не равна мысли.** 100 слов с переворотом причины сильнее 200 слов хора. Порог 80+ — грубый сито, не качество.
4. **Финал часто врёт.** Хор «жизнь прекрасна / просто начать / как-то так» закрывает ролик, тезис жил в середине. Prompt 1 «начало vs конец» обязателен; инструмент автору не должен хвалить финал.
5. **Похвала и комплимент сдвигают адресата.** Слоган «для себя» после «ребята зашло» уже про них. Для стиля это золото; промпт 2 должен спрашивать, для кого речь *после* отклика.
6. **Один жест — много объяснений.** Столб/чай нельзя схлопнуть в «автор про встречи».
7. **Честный обрыв сильнее дописанного лекарства.** Сопротивление, обход точки, парадокс без рецепта. Шлюз должен пропускать их как тезис, не как «недоделанный совет».
8. **Опора почти всегда «я», числа — якорь дней, не эффект.** Иначе 270 дней читаются как доказательство метода.
9. **STT — соавтор.** «Салу», обрывы, строчная в начале. Ядро «словами автора» иногда словами распознавателя. Помечать, не чинить молча.
10. **Промпты врут в одну сторону: достраивают архитектуру.** Почти никогда не «недоговаривают», если их не остановить. Стоп-правила важнее умных вопросов.
11. **Гипотеза почерка с пилота ядовита**, пока не встретила опровержение. «Автор за случайность» и «автор = ежедневность» не выжили бы адвокат дьявола.
12. **Для продукта** годится зеркало (тезис / нет, чужая причина, хор, вопросы), не чеклист приёмов hadunkin и не полевые жесты как советы.

## 6. Что оставить как есть

- Запрет оценки, переписи, советов внутри анализа.
- Тема ≠ тезис.
- Prompt 2/3 не на каждый ролик.
- Неопределённость отдельным блоком.
- Генеративный принцип ≠ совет по хуку.
- Гипотезы ≠ портрет.
- Отдельность Vocal-шкалы.
