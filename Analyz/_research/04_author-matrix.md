## 1b. Что дали четыре новых корпуса

### Belokon

Медицинский разъяснитель. Повод шире мифа: вопрос, объект, случай, личный опыт. Сильные переносимые ходы — **развести смешиваемые категории** (тест ≠ диагноз) и **число → решение** (абсолютный vs относительный риск). Предмет в кадре может заменить завязку. Longform эфиры — отдельно, не умножают Reels-формулы.

### Komarovskiy

Тот же научпоп-класс, но другая точность операции: не «опровергнуть», а **условное опровержение** (сохранить рациональное зерно, отделить связь от вывода). Повторяется **шкала между двумя крайностями** и **триаж вместо самодиагностики**. Реклама не ломает объяснение, а **подменяет функцию финала** — это продуктово важнее, чем ещё один миф-ролик. Есть финалы без совета (клубника как ботанический парадокс).

### Hakamada

Единственный новый жанр в этой четвёрке: **Q&A / философская операционализация**. Мысль часто начинается с чужого вопроса и чинит его рамку, а не факт. Полюса используются как двигатель, итог — баланс или область применимости, не всегда императив. Опора — определение и образ, не исследование. Ближе к Ira/hadunkin по «я» и абстракции, дальше от врачей.

### Lermontova

Карьера/бизнес — пересечение с Alina. Функция корпуса: **повысить определённость проблемы**, а не одна формула. Опоры честно разные (данные / аналогия / опыт) и их нельзя повышать в статусе. Depth-слой есть, но для матрицы достаточно: ещё один предприниматель мало двигает таблицу. Диалоги без диаризации не входят в авторскую модель.

## 2. Общее / различное / неизвестно

### Общее (укрепляется)

1. Готовый вход → смена рамки (механизм, категория, критерий, более узкое правило).
2. Несколько режимов; единый шаблон корпуса ломается. «Миф→опровержение→совет» ни у кого не покрывает большинство FULL.
3. Серия/тема ≠ независимое подтверждение.
4. Финал не обязан быть советом (срез, вопрос, афоризм, нормализация, отказ, наблюдение).
5. Тип опоры надо маркировать: «я», случай, число, модель, определение, исследование — разные статусы.
6. Коммерческий финал может сохранить объяснительные операции и сменить только выход (Komarovskiy; частично Lermontova/Alina).

### Различное

| | ниша | тип модели | «я» | числа |
|---|------|------------|-----|-------|
| hadunkin | состояние/камера | полевой жест | сильно | якорь длительности |
| Ольга | пищевая химия | доза/регламент | слабо | доза/LD50 |
| Marys | нутрициология+быт | базы→варианты | средне | редко центр |
| Ira | психология выбора | камушки/график | сильно | редко |
| Alina | бизнес/маркетинг | сцена+мини-расчёт | средне | мини-модель решения |
| Belokon | гинекология/репро | категория + порог | средне (вход, не норма) | риск/порог → решение |
| Komarovskiy | педиатрия/быт-медицина | одно различение, шкала | слабо-средне | калибровка обещания |
| Hakamada | Q&A / смысл жизни | определение, полюса, образ | средне-сильно | почти нет |
| Lermontova | карьера | контраст / аналогия / цифра | средне | исследование как один из режимов |

### Пока неизвестно

- Переворот рамки **вне** advice-жанра (кино, город, история предмета, спорт-разбор без «исправь жизнь»)? Hakamada ближе всех, но всё ещё жизненный совет.
- Устойчивый финал без CTA и без «сделай» как **норма корпуса**, а не редкий контрпример?
- Поле как носитель мысли — по-прежнему только hadunkin.

## 4. Vocal: операции

### Ядро (общее, можно класть в систему)

1. Готовый вход → уточнить рамку механизмом или более узким правилом.
2. Ярлык/слово → критерий или различие двух категорий.
3. Граница / контрпример / статус опоры.
4. Финал по функции: действие | критерий | вопрос | наблюдение | нормализация | CTA.
5. **Условное опровержение**: сохранить рациональное зерно, отделить связь от вывода (Komarovskiy; рядом Belokon/Ольга).
6. **Маркировать тип опоры** и не повышать статус (Lermontova H3; общее).

### Укрепляют новые корпуса

7. Число → решение с единицей, знаменателем и порогом (Belokon; рядом Alina-расчёт).
8. Объект → устройство → выбор (Belokon).
9. Шкала между крайностями + параметры переключения (Komarovskiy; рядом Hakamada-полюса).
10. Триаж: симптом → альтернативы → порог помощи, без диагноза (Komarovskiy).
11. Проверка рамки вопроса / скрытой предпосылки (Hakamada; рядом Ira).
12. Коммерческий маршрут отдельно: сначала нейтральный вывод, потом оффер (Komarovskiy).
13. Случай → механизм → правило с отделением частоты от драмы (Belokon; рядом Alina/Hakamada).

### Пока не обобщать

- hadunkin: поле, срез без рецепта.
- Ira: снятие эвфемизма; парадокс «чем сильнее попытка»; longform→карточка мысли.
- Ольга: калибровка риска / факт≠катастрофа (частично перекрыто Komarovskiy).
- Marys: конструктор быта, хроника правила.
- Hakamada: афористический финал и отказ отвечать по чужой рамке — мало независимых корпусов.
- Lermontova: карьерная аналогия (Гарвард=акция) — частный случай «модель выбора», уже есть у Alina.

**Не переносить:** лексику, лид-магниты, чужие «исследования» без статуса, медицинские факты без компетенции, голос гостя, биографию автора.

## 5. Зоны покрытия и дыры

| зона | кто закрыл | насыщение |
|------|------------|-----------|
| мотивация / состояние | hadunkin, Ira | достаточно для калибровки |
| научпоп здоровье/еда | Ольга, Marys, **Belokon, Komarovskiy** | **перекрыто** — ещё один врач почти не сдвинет оси |
| бизнес / карьера | Alina, **Lermontova** | достаточно; третий предприниматель — низкий приоритет |
| Q&A / абстракция→операция | **Hakamada** | один корпус; полезен контраст к врачам |
| продукт: диалог→карточка мысли | Ira longform | отдельно |
| коммерция vs мысль | Komarovskiy (явно), Alina/Lermontova | достаточно зафиксировать |

**Дыра та же:** автор **не-advice** — разбор вещи в мире без «исправь здоровье/карьеру/себя». Ещё один врач, нутрициолог или карьерный коуч таблицу не сдвинет.

Следующий корпус выбирать по дыре: кино / город / предмет / спорт-разбор / длинный репортаж — или сознательно другой регистр (юмор без тезиса только как граница, не как Author Model).
