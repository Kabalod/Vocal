# План и правила

## Зачем

Собрать, **как устроен живой автор**, чтобы потом опираться на это в Vocal. Не ставить баллы.

Три слоя идут **только по очереди**:

1. **Смысл** — тезис, карта, опора, начало/конец. Без оценок.
2. **Механика** — хук, удержание, плотность, голос. Вход: смысл. Почерк = гипотеза.
3. **Мышление** — «обычно считают X, автор видит Y» и генеративный принцип. Не на каждом ролике.

## Правила корпуса hadunkin

- Один результат на Instagram-id. Если дубль транскрипции — берём более полную / позднюю.
- Кредиты STT (`DimaTorzok`, «редактор субтитров») и пустышки (<8 слов) не анализируем.
- Полный Prompt 1 на клипе ~40 слов врёт тезис. Для улицы / микро — усечённый смысл: есть ли мысль вообще.
- Prompt 2 — только если в смысле был **реальный тезис**, либо на пилоте для калибровки (тогда помечаем статус).
- Prompt 3 — только если есть собственный вывод автора. Иначе файл с `статус: не применялся`.
- Не путать тему с тезисом. Не додумывать намерение, которого нет в тексте.
