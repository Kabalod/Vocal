ЭТАП 1. PROMPT 0 — все ID

Сначала ищи причины SKIP или LIMITED.

entry_type, ровно один:
мысль / история / наблюдение / процесс / диалог / мантра / реклама / полевой эпизод / смешанный / мусор_STT

thesis_possible: yes | no | unclear
enough_for_sense: yes | no
decision: FULL | LIMITED | SKIP
duplicate_of: instagram_id или null
reason: одно предложение

FULL — тезис правдоподобен, текста хватает.
LIMITED — жест, настроение, процесс, мантра, диалог без одной архитектуры, серия без автономного вывода.
SKIP — пусто, кредит STT, «Продолжение следует...», реклама без речи, точный дубль текста.

Не анализируй мысль.

Выход этапа 1: файл 00_prompt0-gateway.jsonl
Одна строка JSON = один instagram_id, поля:
{
  "instagram_id": "",
  "word_count": 0,
  "entry_type": "",
  "thesis_possible": "yes|no|unclear",
  "enough_for_sense": "yes|no",
  "decision": "FULL|LIMITED|SKIP",
  "duplicate_of": null,
  "voice": "автор|гость|смесь|неясно",
  "reason": ""
}

После файла — сводка:
- counts FULL / LIMITED / SKIP
- counts entry_type
- empty_text и технических SKIP отдельно
- 5 примеров ID на каждое решение

ЭТАП 2. ПИЛОТ 12 — только после шлюза

Выбери 12 ID, смешанно, не пересекающиеся по функции:
- 4 FULL, похожие на «мысль/наблюдение»
- 4 FULL или LIMITED, которые МОГУТ быть неопределённостью (вопрос, две рамки, обрыв, «не знаю»)
- 4 ломают гипотезу дыры: совет, CTA, влог, список, промо, чистая сцена

Пометь, почему каждый ID в корзине.

Для каждого из 12 — Prompt 1 MODE=screening (коротко, те же поля). Порядок:
1) Есть ли различимый тезис?
2) Альтернатива: только тема / сцена / настроение / призыв / формула?
3) Если тезис не отделяется: thesis=null, thesis_present=false. Остальное null или [], кроме uncertainties и routing.
4) Иначе заполняй.

Дополнительно к схеме — три метки дыры (не вместо тезиса):
- frames_in_conflict: true|false|null  (столкнуты ли две рамки/версии)
- ending_function: совет|вопрос|наблюдение|обрыв|CTA|неясно|нет в тексте
- uncertainty_held: true|false|null  (неопределённость УДЕРЖАНА до конца, не сброшена советом)
