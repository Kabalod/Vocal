# Глубокий Prompt 1–3 по трём выборкам

## Метод

Поскольку исходный мастер-промпт называет Prompt 1–3, но не задаёт их отдельные схемы полей, глубина выполнена в трёх проверяемых слоях:

1. **Prompt 1 — смысловой каркас:** вход, тезис, операция, поддержка, финал.
2. **Prompt 2 — логика и границы:** переходы, режим доказательства, неопределённость, место возможного разрыва.
3. **Prompt 3 — абстракция для Vocal:** переносимая операция и риск искажения без копирования автора.

Решения Prompt 0 не менялись. Внешняя истинность утверждений не проверялась.

## Сводный результат глубины

Глубина не подтверждает единую формулу ролика. Она подтверждает общий **маршрутизатор неопределённости**:

1. определить, что именно зрителю непонятно — причина, диагноз, риск, действие, доказательность, выбор или смысл;
2. выбрать соответствующую операцию — различение, триаж, шкалу, причинную цепочку, карту вопросов, список либо историю;
3. подобрать режим поддержки, достаточный именно для этой операции;
4. завершить той функцией, которую обещал вход;
5. отдельно маркировать коммерческий переход.

Это уточняет прежнюю гипотезу: `миф → механизм → совет` — только один маршрут внутри более общей системы.
