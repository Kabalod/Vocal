# Длинные эфиры: идеи для развития Vocal

## Зачем выделен отдельный контур

Три эфира исключены из анализа Reels, потому что каждый `instagram_id` содержит множество вопросов, ответов, отступлений и коммерческих фрагментов. Здесь они рассматриваются не как сценарии роликов, а как материал для проектирования диалога Vocal с пользователем.

| ID | Слов | Основная тема эфира | Решение для Reels |
|---|---:|---|---|
| `DcinpTbE6uB` | 15 816 | деньги, работа, повторяющиеся решения, свобода выбора | SKIP — `longform_live_not_reels` |
| `DcJmqfliK0O` | 15 686 | способность справляться, риск, ресурсная ёмкость, обязательства | SKIP — `longform_live_not_reels` |
| `DcY1hGACPEY` | 16 280 | отношения, мотивы поведения, повторяющиеся конфликты, коммуникация | SKIP — `longform_live_not_reels` |

## Главный продуктовый вывод

Полезная для Vocal единица здесь — не готовый ответ автора, а **последовательность уточняющих операций**:

`исходная фраза пользователя → уточнение значения → возможные последствия → повторяющийся выбор → цена выбора → доступное следующее действие`

Эфиры показывают, что одного вопроса пользователю недостаточно. Агенту нужен управляемый диалог, который углубляет материал, но сохраняет формулировки как гипотезы и позволяет пользователю их отвергнуть.

## Состав

- `00_longform-map.json` — карта тематических сегментов с дословными якорями.
- `01_question-mechanics.md` — повторяющиеся операции уточнения вопроса.
- `02_vocal-opportunities.md` — функции продукта, которые можно вывести из материала.
- `03_product-backlog.md` — приоритетный план проверки продуктовых гипотез.
- `longform-evidence.json` — 14 дословно проверенных цитат.

## Ограничения

- Это текстовый анализ без внешней проверки утверждений автора.
- Вопросы аудитории и ответы автора находятся внутри одного текста; карта сегментов не является диаризацией.
- Точные таймкоды отсутствуют, поэтому сегменты заданы тематически, а не по секундам.
- Авторские названия систем, классификации и причинные объяснения нельзя переносить в Vocal как факты.
- Коммерческие части эфиров не используются как продуктовые доказательства.
