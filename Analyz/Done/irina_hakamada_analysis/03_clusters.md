# Кластеры операций построения мысли

Кластеры считаются только по FULL-записям; каждому учтённому ролику назначен один первичный кластер. Тематическое сходство само по себе не учитывалось.

| Имя кластера | Формула входа | Сколько роликов | 3 ID-представителя | 1 контрпример |
|---|---|---:|---|---|
| Переработка вопроса | вопрос → проверка понятия/предпосылки → новая рамка | 14 | `DaPS_APtXCy`, `DcNd90ttXsA`, `DdDinL-NwI0` | `Dbpa3E0NF1l` |
| Противоположности и баланс | полюс А ↔ полюс Б → функция/баланс | 13 | `DauMjAct5Af`, `DbAOH1Et5SD`, `DciGnNYMVP2` | `Dbci4LEtb_Z` |
| Механизм в действие | проблема → разложение → шаг | 17 | `Da4fvYtN2nh`, `DahUljcNjak`, `DazWKGtt7Qt` | `DYL-btMNLyd` |
| Абстракция через модель | абстракция → образ/пример → возврат к тезису | 14 | `DacJNK4tULa`, `DaE_28cNvr6`, `DaUb-YBNjUv` | `DbKhPrMNhfk` |
| Личный эпизод в вывод | сцена → наблюдение → обобщение | 11 | `DaKHoXttRPX`, `DbBTrEAM-s0`, `DcaV6L-N3KM` | `DaKHoXttRPX` |

**Не отнесены к устойчивому первичному кластеру без натяжки:** 11 FULL-записей — `Dbci4LEtb_Z`, `DbfHmhRNiqC`, `DbFXqmKtFH8`, `DbkRM7tN_PW`, `DWlNGnOjH7v`, `DWnq6ZpDIN_`, `DXZDkIyDLNa`, `DYL-btMNLyd`, `DYRJKmbt59S`, `DZMW5bxN_7B`, `DZZO1y3t7Ge`.


## Редкие формы — пока не кластер

- чистая короткая максима без развёртки;
- категорическое социальное утверждение без внутреннего уточнения;
- описание определения без примера или действия;
- ситуативный юмористический поворот.

## Влияние серийности

Повторы тем «наблюдатель», «хаос», «энергия», «мужское/женское» могут происходить из тематических серий. ID остаются отдельными роликами, но эти повторы не используются как единственное основание кластера: кластер определяется функцией переходов.

## Трудные случаи

Промо, анонсы, смешанный диалог и бытовые сценки вынесены из частот основной таблицы. Некоторые короткие FULL-записи допускают более одного прочтения; ради проверяемости им не назначался кластер, если основной переход нельзя выделить без натяжки.
