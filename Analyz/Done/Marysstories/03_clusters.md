# Смысловые кластеры

Кластеры описывают функцию сценария, а не тему.

| Кластер | Повторяющаяся операция | Примеры ID | Граница |
|---|---|---|---|
| Аудит мифа или обещания | взять готовое утверждение → проверить доказательства/механизм → ограничить вывод | `Da_EDoTIxjG`, `Daj83coIAHM`, `DXcWFh2jP0c`, `DYz-zRio5OV`, `DZDRhKVolvp` | не универсален для личных и рецептурных роликов |
| Нюансировка бинарного совета | признать часть тезиса → показать ловушку/условие → дать условный ответ | `Da5daNoIUd9`, `DZUMuzWoAZl`, `DZXsKkUIzHq` | иногда итог остаётся прямым вердиктом |
| От самообвинения к причинной цепочке | снять ярлык воли → объяснить условия поведения/физиологии → предложить действие | `DbEDiLEtfun`, `DWmRFd-jAla`, `DWUchtpCPSm` | требуется исходный моральный ярлык |
| Конструктор быта | разделить задачу на базы → показать комбинации → сократить повторяющееся усилие | `Dbllhu-Ihn0`, `Dbi4l4nouB6`, `DbbXCxfolKF`, `DboLIZvoYXh` | кулинарный подкорпус |
| Личная хроника правила | ввести правило/челлендж → столкнуть с эпизодом → пересобрать | `DUc3AakiBxw`, `DVJI926CABe`, `DVq_Ro-DJHf`, `DWBx76pCHlx` | отдельный режим, не экспертное доказательство |
| Демонстрация или рецепт | обещать конкретный результат → показать последовательность → предъявить блюдо/варианты | `DTyiS1RCES2`, `DZz7j3lo4LW`, `DU-GPgFCMFB` | текст не передаёт визуальную часть полностью |
| Диалоговая сценка | вопрос/ситуация → обмен реакциями → бытовая развязка | `Da8eMX5opmQ`, `DbY0QWeIxJU`, `DZHssGtoFnL` | без диаризации атрибуция ограничена |

## Не объединять

Экспертный аудит, личную хронику, рецепт и диалог нельзя сводить к одной линейной формуле. Общими могут быть только верхнеуровневые функции: входное напряжение, преобразование исходной рамки и функциональный финал.
