# Корпусные гипотезы: Marysstories

## Метод

Не оценивать автора; не объяснять просмотры; один ID — один ролик; не приписывать чужую речь; дословные цитаты; «нет в тексте» допустимо; каждую гипотезу проверять контрпримером.

Положительные подтверждения взяты преимущественно из FULL. LIMITED используются для границ; SKIP не используются как смысловые доказательства.

## Что ломает единую модель автора

`DbLY67dorPO` строится как развернутая хроника поиска дома; `DTyiS1RCES2` — рецепт; `Da8eMX5opmQ` — игровая переброска реплик; `DZz7j3lo4LW` — демонстрация приготовления. В них нет обязательного аудита мифа. Поэтому «миф → научное опровержение» — крупнейший режим, но не универсальная формула корпуса.

## Итоговая осторожная формулировка

В экспертных монологах автор часто берёт тревожное или бинарное утверждение и переводит его в более условную картину через механизм, состояние доказательств или границу применимости. Личные хроники, рецепты/демонстрации и диалоги образуют самостоятельные режимы.

## Обновление после глубокого Prompt 1–3

Подробная проверка 25 ID не изменила решения Prompt 0, но сузила две серийные гипотезы.

- H1 остаётся **REFINED**: аудит обещания устойчив в экспертном режиме, но не описывает весь корпус.
- H2 остаётся **CONFIRMED** только для входов с самообвинением.
- H3 подтверждена как типичная экспертная операция: признать верную часть → добавить условие/скрытую цену → сменить вывод.
- H4 уточнена до **REFINED**: конструктор повторяется, но значительная часть примеров принадлежит одной коммерческой серии о заготовках.
- H5 уточнена до **REFINED**: правило → испытание → пересборка подтверждено внутри серии «12 вещей», независимость примеров ограничена.
- H6 **CONFIRMED**: режим ролика определяет допустимый тип опоры и финала; подробности — в `07_depth-synthesis.md`.

### Чего корпус не доказывает

Корпус не доказывает влияние механик на просмотры, внешнюю истинность научных заявлений, авторство всех реплик в диалогах, качество визуальной демонстрации и универсальность формул за пределами этого корпуса.
