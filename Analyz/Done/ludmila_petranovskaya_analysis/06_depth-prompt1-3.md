# Глубокий Prompt 1–3 по трём выборкам

## Метод

Этот проход не меняет Prompt 0. Для каждого ID проверены: источник входа, исходная рамка, тезис, операция преобразования, опоры, переходы, функция финала и ограничение. Затем записи сопоставлены внутри и между выборками. Анализ относится только к тексту; внешнего фактчекинга, оценки автора и выводов о просмотрах нет.

# Prompt 2. Сопоставление выборок

## Что выдержало глубину

1. **Деавтоматизация исходной рамки.** Входом может быть миф, ярлык, симптом, вопрос, страх или моральный вывод. Инвариант — приостановить очевидное толкование.
2. **Различающий критерий важнее контртезиса.** Равенство/односторонность, событие/след, напряжение/отсутствие восстановления, нормальный конфликт/нарушение баланса позволяют применять мысль к новым случаям.
3. **Пример выполняет логическую работу.** Он используется как проверка границы, контрфактическая пара или модель причинной петли; простая иллюстрация встречается, но не является единственным режимом.
4. **Смена позиции часто важнее списка действий.** Финалы предлагают быть помощником, устойчивым взрослым, ответственным учреждением или исследователем вместе с ребёнком.
5. **Реалистичный остаток сохраняется.** Недовольство не обязано исчезнуть, конфликт остаётся, школа не становится любимой мгновенно, ресурс остаётся ограниченным.

## Что изменилось относительно первого прохода

- Формула «миф → уточнение → пример → совет» оказалась слишком узкой.
- «Нормализация» не всегда финал: она может стоять в середине и освобождать место для ответственности.
- Метафора не обязательна; функциональный эквивалент — контрастный пример, кейс или встречный сценарий.
- В плотных роликах основная единица — не тезис, а **модель выбора**: различия, условия, ветки и роль участника.
- Длинные эфиры не являются эталонами Reels, но содержат сырьё для базы возражений, вопросов и механизмов.

# Prompt 3. Перевод глубины в генератор

## Схема A. Диагностическое различение

**Входные поля:** фраза аудитории; два смешанных явления; наблюдаемый критерий; последствия смешения; исключения.

**Алгоритм:** `дать фразе прозвучать → назвать смешение → ввести один критерий → проверить на паре контрастных сцен → показать, как меняется решение → добавить границу`.

**Запрет:** не генерировать новый термин, если пользователь не может объяснить критерий обычным языком.

## Схема B. Симптом как дерево причин

**Входные поля:** наблюдаемый симптом; возможные контексты; признаки каждой ветки; действие; предел компетенции.

**Алгоритм:** `отказать в универсальном рецепте → назвать 2–4 независимые ветки → для каждой дать проверочный вопрос → связать ветку с действием → завершить общей позицией`.

**Запрет:** не выдавать список за диагностику; медицинские и правовые ветки должны вести к профильной помощи.

## Схема C. Петля эскалации

**Входные поля:** исходное событие; автоматическая реакция; воздействие реакции; усиленный ответ; точка разрыва.

**Алгоритм:** `сцена → реакция → обратный эффект → наглядная модель → альтернативная реакция → реалистичный остаток`.

**Запрет:** не обещать исчезновения исходного чувства или конфликта.

## Схема D. Смена роли

**Входные поля:** участник; что он пытается контролировать; что реально в его власти; ответственная роль; допустимое действие.

**Алгоритм:** `показать предел прямого контроля → назвать доступную функцию → дать 1–3 действия из этой функции → проверить, не присвоена ли чужая ответственность`.

**Запрет:** контекстуализация не должна оправдывать насилие, бездействие или уход от обязанности.

## Схема E. Траектория вместо снимка

**Входные поля:** тревожащий эпизод; предыдущий этап; следующая функция; переходный маятник; критерий опасности.

**Алгоритм:** `назвать норму этапа → показать, почему она должна измениться → описать неровный переход → отделить переход от устойчивой патологии → дать позицию сопровождающего`.

**Запрет:** не нормализовать всё подряд; обязательно спросить о длительности, односторонности, безопасности и функционировании.

## Схема F. Добыча идей из длинного эфира

**Входные поля:** реплики с атрибуцией; вопросы ведущего; возражения; механизмы; кейсы; незавершённые темы.

**Алгоритм:** `разделить голоса → извлечь атомарные вопросы → для каждого найти автономный тезис → оставить только опору того же спикера → проверить завершённость → создать отдельные карточки, не склеивая исходные ID`.

**Запрет:** не считать весь эфир одним Reels и не приписывать ведущему тезисы гостя.

## Контроль качества для Vocal

- Можно ли назвать исходную автоматическую рамку одним предложением?
- Есть ли критерий, который работает на новом примере?
- Выполняет ли пример функцию проверки, а не украшения?
- Соответствует ли действие той причине, которую текст выделил?
- Ясно ли, чья ответственность и чья речь?
- Сохранён ли реалистичный остаток вместо обещания полного решения?
- Может ли ролик существовать без копирования фраз, биографии и персонажей автора?
