# Генеративные принципы для Vocal

### Проверка смысловой подмены

**Когда применять:** пользователь начинает со спорного правила, ярлыка или утверждения «X означает Y».

**Вход:** исходная формулировка, наблюдаемый факт, два возможных понятия, контекст.

**Ход:** `зафиксировать исходное равенство → разделить наблюдение и трактовку → определить различающиеся понятия → сформулировать более узкий тезис → проверить исключение`

**Проверка:** новое различение должно менять понимание ситуации и подтверждаться материалом пользователя, а не только звучать остро.

**Риск:** создать ложную дихотомию или уверенно объявить «подменой» то, для чего нет данных.

### От поведения к проверяемому механизму

**Когда применять:** сценарий описывает проблемное действие человека как готовое объяснение.

**Вход:** наблюдаемое действие, момент начала, изменения контекста, возможные чувства/потребности, альтернативы.

**Ход:** `описать только наблюдаемое → назвать, что неизвестно → предложить несколько возможных причин → указать способ проверки → выбрать ответ, не усиливающий симптом`

**Проверка:** причина не должна выдаваться за факт без наблюдений; в сценарии есть вопрос или признак, который отличает версии.

**Риск:** бытовая психодиагностика и чрезмерно уверенная причинность.

### Согласование совета с причиной

**Когда применять:** после объяснения нужно перейти к практическому финалу.

**Вход:** механизм, доступный пользователю ресурс, безопасное действие, граница применимости.

**Ход:** `сверить совет с механизмом → выбрать один первый шаг → указать момент выполнения → добавить границу/условие остановки → сформулировать проверяемый эффект`

**Проверка:** действие конкретно, выполнимо и не противоречит объяснению.

**Риск:** универсальный совет в медицинской, правовой или кризисной ситуации без нужной квалификации.

### Частный случай как иллюстрация, а не доказательство

**Когда применять:** у пользователя есть личная история, из которой хочется сделать общий вывод.

**Вход:** событие, поворотный момент, наблюдение, предполагаемый общий механизм, предел обобщения.

**Ход:** `сжать обстоятельства → выделить момент смены понимания → назвать иллюстрируемый механизм → отделить опыт от общего знания → дать осторожный вывод`

**Проверка:** слушатель понимает, что подтверждает история, а чего она не подтверждает.

**Риск:** превратить единичный опыт в универсальную закономерность.

### Локально завершённая часть серии

**Когда применять:** одна тема делится на несколько коротких роликов.

**Вход:** общий тезис серии, тезис каждой части, зависимость между частями, финальная функция.

**Ход:** `разделить общий вопрос → дать каждой части автономный микроответ → убрать критическую зависимость от предыдущего ID → добавить локальный вывод → только затем мост к следующей части`

**Проверка:** отдельный ролик можно пересказать одним предложением без просмотра соседней части.

**Риск:** тизер заменяет ответ, а повтор серии ошибочно принимается за несколько независимых доказательств.

### Этическая маркировка знания

**Когда применять:** сценарий касается исследования, здоровья, права, истории или чужого поведения.

**Вход:** источник утверждения, компетенция пользователя, степень уверенности, альтернативное объяснение.

**Ход:** `отделить личный опыт от источника → назвать уровень уверенности → убрать недоказанную категоричность → указать предел применимости → при необходимости направить к специалисту`

**Проверка:** ясно, где факт из источника, где интерпретация, где личный опыт.

**Риск:** дисклеймер становится декоративным и не исправляет необоснованное утверждение.

### Проблема к предложению без подмены вывода

**Когда применять:** разговорный ролик должен естественно привести к продукту или событию.

**Вход:** конкретная потребность, механизм проблемы, релевантная функция продукта, ограничения предложения.

**Ход:** `показать проблему → объяснить связь с потребностью → назвать функцию предложения → отделить обещание от гарантии → дать прозрачный CTA`

**Проверка:** продукт решает именно названную задачу; если убрать CTA, смысловая часть всё равно остаётся честной и законченной.

**Риск:** рекламное обещание маскируется под доказанный психологический вывод.

## Что не переносить

- характерные фразы, панчлайны и узнаваемую стилизацию автора;
- личную историю, биографию и семейные детали;
- узнаваемых персонажей и названия авторских рубрик;
- ругательства и индивидуальные речевые привычки;
- отраслевые утверждения за пределами компетенции нового пользователя;
- голос гостей и реплики детей из смешанных диалогов;
- рекламные обещания и CTA без самостоятельной проверки;
- тематическую поверхность автора вместо операции построения мысли.
