Глубина выполнена последовательно: типичные → плотные → ломающие модель. Для каждого ID: Prompt 1 фиксирует анатомию текста, Prompt 2 — смысловую операцию, Prompt 3 — абстракцию для Vocal. Внешний фактчекинг не проводился.

1. Главная повторяющаяся операция точнее описывается как **диагностическое переименование**: видимый случай получает рабочую категорию, после чего меняется решение.
