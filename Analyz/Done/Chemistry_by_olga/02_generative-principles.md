# Vocal-слой: переносимые операции

Это операции мышления, не реплики, не персона и не сценарий для копирования автора.

## Базовая операция для кластера разборов

1. Извлечь тревожное утверждение без усиления.
2. Разделить наблюдаемый факт и вывод, который к нему добавили.
3. Выбрать вердикт: ложь; факт с неверным выводом; реальное локальное нарушение; недостаточно данных; риск зависит от дозы или условий.
4. Найти перепутанные категории: обнаружено/добавлено, запрещено/токсично, опасность/риск, животные/люди, плавление/переваривание.
5. Объяснить один причинный механизм, достаточный для этой ошибки.
6. Выбрать доказательство по задаче: состав, функция, регламент, доза, дизайн исследования, производство, демонстрация или опыт.
7. Добавить одно сопоставимое бытовое сравнение, сохранив дозу и условия.
8. Назвать границу знания и вернуть зрителю безопасное действие.
9. Выбрать функцию финала: вывод, вопрос, следующий ролик, источник, CTA или эмоциональная разрядка.

## Отдельные архитектуры

### Факт реален, катастрофический вывод — нет

`признание факта → реальный путь вреда → относится ли он к зрителю → чего не делать → что делать`

### Перепутаны понятия

`чужая формула → два разных понятия → короткое определение → следствие различия → вывод`

### Страшное исследование

`громкий вывод → объект исследования → доза → путь воздействия → измеренный эффект → предел переноса`

### Практическая демонстрация

`бытовой тест → наблюдение → почему тест неоднозначен → корректный способ проверки → действие`

### Серия

`общая тема → один миф на один ID → минимальный самостоятельный контекст → локальный вывод → мост к следующему ID`

### Коммерческий ролик

`потребность → проверяемое свойство продукта → ограничение или личная оценка → прозрачный рекламный CTA`

Коммерческую задачу маркировать отдельно: она меняет выбор аргументов.

## Контроль генерации

- Есть ли в тексте собственный тезис, или честный ответ — `нет в тексте`?
- Не превратилось ли отсутствие доказанного вреда в обещание абсолютной безопасности?
- Проверяет ли доказательство именно заявленную ошибку?
- Сопоставимы ли дозы, пути воздействия и условия сравнения?
- Отделены ли исследование, регламент, профессиональный опыт и личный вкус?
- Понятен ли один ID без склеивания с соседним?
- Сохраняется ли смысл после удаления шутки и CTA?

## Что не переносить

- авторские панчлайны, ругательства и узнаваемые фразы;
- персонажей и реквизит вроде «шерифа»;
- автоматическое полное опровержение любой страшной новости;
- уверенность за пределами данных и компетенции;
- научную лексику без механизма;
- скрытие коммерческого характера интеграции;
- медицинские назначения конкретному человеку;
- голос гостей из эфиров и интервью.
