# 04. Каркас студии `/reels/[id]` и рабочий цикл

## 1. Назначение и границы

Создать устойчивую оболочку одной мысли: загрузка по id, контекст, local navigation «Дубли / Диалог / Сценарий», возврат и route states. Содержательные циклы пока не реализуются.

## 2. Предварительные условия и зависимости

- P00–P02 приняты.
- Изучены `WORKING_CYCLE_CHECKPOINT_2026-09-15.md` и `working-cycle-output/review.html` с prototypes.
- Подтверждены loader/query и not-found/access-error semantics.

## 3. Точные результаты

- Deep-linkable `/reels/[id]` загружает реальную мысль; loading, not found, access/server error, retry.
- Shell сохраняет global «Мысли / Профиль».
- Только внутри мысли local nav «Дубли / Диалог / Сценарий»; active связан с URL/согласованным state и переживает reload.
- Заголовок/context и back к `/reels` едины.
- Нереализованное content имеет честные минимальные states без fake business logic.
- Layout boundaries позволяют малые следующие этапы без монолита.

## 4. Не входит в этап

- AI messages/proposals, script generation/editor.
- Recording/processing/takes/results/path/polaroid.
- API entities/status transitions.
- Legacy redirects.

## 5. Критерии приёмки и проверки

- Direct open/reload каждой local tab не теряют thought id.
- Global/local nav не смешаны; local tabs вне мысли отсутствуют.
- Back возвращает в list без потери сохранённых данных.
- Invalid id и server error различимы, не выглядят success.
- Mobile tabs доступны keyboard/touch без overflow.
- Следующие этапы подключают slots без замены layout.

## 6. Риски и известные ограничения

- Router может использовать query state; выбрать минимальное решение с deep link.
- Placeholders не должны выглядеть как сохранённые scripts/takes.
- Navigation guard для будущих unsaved data не выдумывать сейчас.
