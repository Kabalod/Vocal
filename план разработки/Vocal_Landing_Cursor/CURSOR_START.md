# Стартовый запрос для Cursor

Реализуй адаптивный лендинг Vocal по `docs/landing/PLAN.md` и макетам `docs/landing/mockups/mobile.png`, `docs/landing/mockups/desktop.png`.

Сначала прочитай AGENTS.md и правила репозитория, проверь git status, текущую ветку, маршруты, дизайн-токены и существующую авторизацию. Не считай исторические SHA принятой базой. Не перезаписывай чужие изменения. Создай отдельную ветку для лендинга, если текущая ветка не предназначена для этой задачи.

Выполняй L00–L07 последовательно. Используй существующий стек, компоненты и шрифты. Не меняй архив, рабочую область, БД, auth и продуктовые статусы ради лендинга. Не добавляй новые библиотеки без технической необходимости. Не делай всю страницу картинкой.

Сохрани мобильный порядок: заголовок → видео → объяснение → CTA → преимущества → диалог → финальный CTA. Desktop сделай по расширенному макету: двухколоночный hero, преимущества, диалог с пояснением, пример результата, обратная связь, FAQ, финальный CTA.

Начни с аудита и зафиксируй реальные маршруты, команды проверок и доступные медиа. Затем продолжай реализацию без повторных согласований обычных технических решений. Если нет видео или утверждённых ответов о приватности, используй честное состояние предварительного просмотра и отметь конкретные блокеры публикации в отчёте; остальную работу заверши. Не выдумывай цены, отзывы, гарантии, метрики и свойства обработки данных.

В конце предоставь SHA, diff, результаты проверок и актуальные скриншоты согласно PLAN.md. Не принимай дизайн автоматически только по зелёным тестам. Публикация production не входит в это задание.
