# Vocal — комплект для Cursor

Дата: 22.09.2026. Это задание на реализацию лендинга в существующем проекте Vocal, а не новый проект приложения.

## Как начать

1. Распаковать папку в `docs/landing/` репозитория Vocal.
2. Открыть `PLAN.md`, затем оба изображения в `mockups/`.
3. Передать Cursor текст из `CURSOR_START.md`.

## Макеты

- [Mobile](mockups/mobile.png) — последняя согласованная мобильная композиция: видео после заголовка, затем описание, кнопка, преимущества и переписка.
- [Desktop](mockups/desktop.png) — последняя расширенная продающая версия с двухколоночными секциями. Предыдущий desktop с вертикальной композицией не использовать.

Макеты — растровые концепты, не готовые компоненты. Текст и интерфейс нужно сверстать, не размещать страницу одной картинкой. Человек, диалог и разбор иллюстративные. Настоящее видео не входит в комплект.

При конфликте приоритет: PLAN.md → указанный макет для соответствующего экрана → разумные адаптивные решения. Все размеры в плане — стартовые CSS-параметры, а не измерения PNG.
